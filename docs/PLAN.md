## 1. 목표

**아이들 관심사** (AI 친구 대화, 게임, 이야기, 도감 테마에 반영)
- 첫째(아들): 로블록스 → AI 친구 Max도 로블록스 오비와 타이쿤을 좋아함, 과학 도감은 "실험실 빌드", 게임 후보 "오비 달리기"
- 둘째(딸): 동물의 숲 → AI 친구 Lily도 섬 꾸미기와 곤충, 물고기 잡기를 좋아함, 과학 도감은 "나의 과학 박물관", 첫 이야기는 동물 친구들의 섬 이야기(창작)
- 게임 이름은 대화 주제로만 쓰고, 앱에 게임 이미지나 공식 캐릭터는 넣지 않는다.


| 대상 | 목표 | 성공 기준 (3개월) |
|---|---|---|
| 첫째 (2015.4생, 초5) | 영어로 좋아하는 이야기를 주저 없이 떠들기, 5학년 수학 완성, 과학에 관심 갖기 | 주 5일 AI 친구와 대화, 대화 중 영어 발화 비율 증가, 수학 레벨 꾸준히 상승 |
| 둘째 (2017.9생, 초3) | 영어로 노는 게 익숙해지기, 3학년 수학, 과학 호기심, 읽기 습관 | 주 5일 미션 완료, "오늘 뭐 해?"를 스스로 묻기 |
| 나 (만 45세) | 비즈니스 영어 프리토킹, AI 지식, 독서 정리 | 주 3회 비즈니스 대화 15분, 월 2권 독서노트 |
| 나 (관리자) | 아이들 대화 기록과 진도 확인, 보상과 난이도 조정 | 매일 밤 5분 기록 확인, 필요하면 다음 날 바로 수정 |

**원칙**
1. **"공부해"가 아니라 "오늘은 뭐 해?"** 영어는 친구와 수다, 과학은 궁금한 문제와 해설, 국어는 다음 화가 궁금한 이야기.
2. **아이 성향에 맞춰 바로 고친다.** 꼼수를 쓰면 그날 밤 막고, 너무 쉬우면 다음 날 어렵게. 그래서 직접 만든다.
3. **끝내면 보상.** 미션을 다 하면 쿠폰("유튜브 30분")과 오늘 푼 문제로 만든 게임이 열린다.
4. **AI가 만든 건 부모가 본다.** 대화 기록, AI가 만든 문제와 이야기는 보호자 화면에서 확인하고 고칠 수 있게 한다.
5. **비용은 예측 가능하게.** 하루 대화 시간 상한, OpenAI 프로젝트 월 예산 한도, 보호자 화면에 오늘 쓴 비용 표시.

## 3. 학습 콘텐츠 설계

### 3-1. 영어: AI 친구와 프리토킹 (핵심)

단어 시험 대신 **원어민 친구와 수다**를 매일 한다. 아이가 좋아하는 주제(마인크래프트, 포켓몬, 학교에서 있었던 일, 먹고 싶은 것, 오늘 한 실험)로 마음껏 떠든다. **영어 단어는 학원에서 배우므로, 이 앱의 영어는 공부 요소 없이 순수하게 노는 프리토킹이다.** 따라 말하기 시키기, 퀴즈, 문법 교정은 하지 않는다.

| 항목 | 설계 |
|---|---|
| 엔진 | OpenAI Realtime API `gpt-realtime-2.1-mini` (음성 입력 → 음성 출력, 실시간으로 끼어들기 가능) |
| 연결 | 브라우저 ↔ OpenAI WebRTC 직접 연결. API 키와 AI 친구 성격(지시문)은 우리 Worker에만 있고, Worker는 연결만 열어 준다 |
| AI 친구 | 아이마다 이름, 성격, 목소리가 있는 친구 캐릭터. 취조하듯 묻지 않고 맞장구치며 자연스럽게 대화 |
| 막혔을 때 | 아이가 한국어로 답해도 그대로 받아 주고 영어로 이어 간다. 10초 동안 말이 없거나 "막혔어요"를 누르면 친구가 "한국어로 말해도 괜찮아!"라고 한국어로 짧게 이끌거나 쉬운 선택지("Minecraft or Pokémon?")를 준다 |
| 수준 | 초3은 아주 쉬운 단어와 천천히, 초5는 자연스러운 속도. 틀린 문법은 지적하지 않고, 친구가 자기 말에서 자연스럽게 바른 표현을 쓴다 |
| 기억 | 대화가 끝나면 요약(주제, 아이가 좋아하는 것, 다음에 물어볼 것)을 저장하고 다음 대화에 넣어 "지난번에 말한 그 크리퍼 잡았어?"처럼 이어 간다 |
| 자막 | 듣기 → 말하기 → 읽기 → 쓰기 순서. 처음엔 AI 말 자막을 다 보여 주고, 보호자가 **자막 가림 비율**(0% → 3% → 5% → 10% …)을 올린다. 나중에 대화 기록으로 이해도를 보고 자동 조절 |
| 시간과 비용 | 하루 상한(기본 초3 15분, 초5 20분, 보호자가 조정). 30분 기준 약 430원(원글 실측, 말을 많이 하면 800원까지) |
| 기록 | 대화 전문(자막), 영어로 말한 비율, 새로 쓴 표현을 저장해 **보호자만** 확인. 아이 화면에는 "오늘 한 이야기"와 "다음에 친구가 물어볼 것"만 |

보호자도 같은 구조로 **비즈니스 프리토킹**을 한다(동료, 거래처, 까다로운 임원 역할). 끝나면 더 자연스러운 표현을 받아 "내 표현" 카드로 복습한다.

기존 1단계의 단어 카드와 따라 말하기는 아이 프로필에서 **기본으로 끈다**(보호자가 원하면 켤 수 있게 코드는 남김). 보호자 본인은 계속 쓴다.

### 3-2. 수학 도전 (적응형 난이도 + 꼼수 방지)

1단계의 학년별 문제 생성기(2022 개정 교육과정, 아래 표)를 그대로 쓰되, **레벨**로 묶어 자동으로 오르내린다.

- 하루 20문제, **화면 숫자 키패드**로 직접 입력(보기 고르기 없음).
- 하루 결과로 다음 날 레벨 결정: 잘하면 +1, 못하면 -1.
- 꼼수 방지 (원글에서 둘째가 일부러 틀려 난이도를 낮춘 일):
  - 5초 안에 틀린 답은 "찍기"로 보고 레벨 계산에서 뺀다(보호자 화면에 찍기 횟수 표시).
  - 최근 7일 최고 레벨보다 두 단계 이상 내려가지 않는다(바닥 = 최고 레벨 - 1).
  - 한 문제에 1분 넘게 손을 안 대면 그 시간은 풀이 시간 계산에서 뺀다.
- 오답노트는 1단계처럼 다음 세션 앞부분에 다시 나온다.

**3학년 (둘째)**
| 단원 | 유형 | 학기 |
|---|---|---|
| 덧셈과 뺄셈 | 세 자리 수 덧셈, 뺄셈 | 3-1 |
| 나눗셈 | 곱셈구구 범위의 나눗셈 | 3-1 |
| 곱셈 | 두 자리 × 한 자리 | 3-1 |
| 곱셈 | 세 자리 × 한 자리, 두 자리 × 두 자리 | 3-2 |
| 나눗셈 | 두 자리 ÷ 한 자리 (나머지) | 3-2 |

**5학년 (첫째)**
| 단원 | 유형 | 학기 |
|---|---|---|
| 자연수의 혼합 계산 | 괄호와 사칙연산 순서 | 5-1 |
| 약수와 배수 | 최대공약수, 최소공배수 | 5-1 |
| 약분과 통분 | 기약분수로 나타내기 | 5-1 |
| 분수의 덧셈과 뺄셈 | 분모가 다른 분수 | 5-1 |
| 수의 범위와 어림하기 | 올림, 버림, 반올림 | 5-2 |
| 분수의 곱셈 | 분수 × 분수, 자연수 × 분수 | 5-2 |
| 소수의 곱셈 | 소수 × 자연수, 소수 × 소수 | 5-2 |
| 평균 | 자료의 평균 | 5-2 |

### 3-3. 두뇌 퍼즐 (자유 놀이)
- 6종: 스도쿠(4×4, 6×6), 숫자 기차(다음 수 찾기), 수 피라미드, 저울, 도형 규칙, 블록 세기
- **하루 미션이 아니라 자유 놀이**(보호자 결정 2026-10-08: 하루 미션이 이미 35~40분). 손을 안 대고 있는 시간은 세지 않는다.
- 2분 막히면 힌트, 3번 틀리면 정답 보기. 난이도는 종류마다 따로 자동 조절.

### 3-4. 공부하면 열리는 게임
- 수학 미션을 끝내면 **오늘 푼 문제로 만든 게임**이 열린다(예: 낚시 게임, 물고기마다 오늘 문제가 붙어 있음, 틀렸던 문제는 금빛 물고기).
- **형제 대결**: 같은 문제 세트로 번갈아 풀고 점수와 시간을 비교. 이긴 아이가 다음 게임 고르기 권한을 갖는다.

### 3-5. 과학 문제 (첫째, 둘째 모두)
- 두 아이 모두 과학에 관심을 갖게 하는 게 목표. **아이들 의견(2026-10-07)에 따라 실험 카드 중심에서 문제 중심으로 바꿨다.**
- 매일 학년에 맞는 과학 문제 5개(객관식, OX). 맞혀도 틀려도 해설을 보고, 틀린 문제는 복습 간격에 맞춰 다시 나온다.
- 3학년 단원(물질의 성질, 자석, 동물, 지표, 물질의 상태, 소리)과 5학년 단원(온도와 열, 태양계, 용해와 용액, 생물, 날씨, 물체의 운동, 산과 염기)에 연결. 첫 배포 100문제(공통 20, 초3 40, 초5 40).
- 처음 맞힌 문제는 도감 카드로 모이고 단원별 배지가 생긴다. 둘째는 "나의 과학 박물관", 첫째는 "실험실 빌드". 캐릭터 옷차림이 매일 바뀐다.
- 이미 만든 실험 카드 40장은 해설 밑 **"🧪 집에서 해 보기"(선택)**로 남긴다. 미션과 무관하고, 하면 보너스 별.
- 오늘 푼 단원은 AI 친구 대화의 주제 칩으로 이어진다.

### 3-6. 국어: 다음 화가 궁금한 이야기 (자유 놀이, 둘째 중심)
- 연재 이야기를 하루 한 화씩(초3 기준 600~1,000자) 읽는다. 마지막은 궁금하게 끊긴다.
- 화 끝에 문제 3개(사실 확인, 추론, 어휘). 다 풀면 다음 날 다음 화가 열린다.
- **하루 미션이 아니라 자유 놀이**(보호자 결정 2026-10-08). 이야기 원고는 기획 쪽(Claude)이 쓰고 **보호자가 읽어 보고 확정**한다. 첫 이야기: 「작은 섬으로 이사 온 날」(docs/stories/small-island.md). 그림은 선택.

### 3-7. 보호자: 독서노트
- 1단계 기능 유지(요약, 질문 카드, 간격 반복). AI 질문 생성은 후순위.

## 5. 기기 구성 (원글 추천)

| 항목 | 권장 |
|---|---|
| 본체 | 중고 Galaxy Fold4 (안쪽 화면 파손 매물 10~12만 원). DeX로 모니터에 띄워 쓰므로 바깥 화면만 멀쩡하면 됨. Note10+는 오래돼 느리고 소리 설정이 번거로움, Fold3는 발열 |
| 연결 | USB-C 허브로 모니터, 키보드, 마우스, 헤드셋(마이크). 아이 하나당 한 대 |
| 설정 | 아이용 구글 계정 + Family Link, 배터리 보호(최대 80%) 켜기, Chrome으로 앱 접속 후 홈 화면에 설치 |
| 마이크 | 대화 품질을 위해 헤드셋이나 마이크 달린 이어폰 권장(스피커 소리가 마이크로 다시 들어가는 문제 감소) |

> 아이마다 기기가 따로 생기면 기록이 기기별로 나뉜다. 보호자 화면을 한곳에서 보려면 **기기 간 동기화(T14)**가 필요하다. 그 전까지는 각 기기에서 보호자 모드를 연다.

## 6. 기술 설계

| 항목 | 선택 | 이유 |
|---|---|---|
| 형태 | 웹앱 + PWA | DeX(Chrome), 태블릿, PC 어디서나 |
| 프레임워크 | Vite + React + TypeScript | 1단계 그대로 |
| 저장소 | `localStorage` → 동기화(T14) | |
| 영어 대화 | OpenAI Realtime API `gpt-realtime-2.1-mini`, WebRTC | 원어민 수준 음성, 실시간 끼어들기, mini로 충분(원글 실측) |
| 텍스트 생성 | OpenAI 소형 텍스트 모델(nano, mini 계열) | 대화 요약, 피드백, 이야기와 실험 카드 초안 |
| 프록시 | Cloudflare Worker | API 키 보관, 대화 연결 열기, 하루 시간 상한, 사용량 기록 |
| 테스트 | Vitest | 순수 로직 |
| 배포 | GitHub Pages (Actions) | |

### Realtime 연결 구조
```
[아이 기기 브라우저]                [Cloudflare Worker]               [OpenAI]
 마이크 → WebRTC offer(SDP) ──────▶ 가족 토큰 확인, 오늘 남은 시간 확인
                                     AI 친구 지시문 + 기억 요약으로 세션 설정
                                     ──── SDP + 세션 설정 (API 키) ────▶ /v1/realtime/calls
 ◀────────── answer(SDP) ────────── ◀──────────────────────────────────
 ◀═════════ 음성, 자막 이벤트 (WebRTC로 OpenAI와 직접) ═════════════▶
 대화 종료 → 자막 기록을 Worker에 보내 요약, 피드백 생성 (텍스트 모델)
```

## 9. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 대화 비용 증가 (말이 많은 날 2배) | 하루 대화 시간 상한을 Worker에서 강제, OpenAI 프로젝트 월 예산 한도 설정, 보호자 화면에 비용 표시, 대화 중 남은 시간 표시 |
| 아이 대화 안전 | AI 친구 지시문은 Worker에만 둠(나이에 맞는 주제, 개인정보 묻지 않기, 위험한 주제는 부드럽게 전환), 대화 기록을 보호자가 매일 확인, 끝난 대화 자막은 모더레이션 검사 후 보호자에게 표시 |
| 아동 개인정보 | 아이 목소리와 대화가 OpenAI로 전송됨. 이름 대신 별명을 쓰게 하고, OpenAI의 데이터 보관 설정과 이용 정책(미성년자 서비스 조건)을 보호자가 확인 |
| 음성 인식, 에코 | 헤드셋 권장, WebRTC 에코 제거 옵션 사용, 시끄러울 때 "눌러서 말하기" 모드 |
| AI가 만든 내용 오류 | 수학 정답은 코드가 계산, 이야기와 실험 카드는 보호자 확인 후 공개 |
| 아이가 금방 질림 | 아이별 맞춤(관심사, 캐릭터, 게임 보상), 기록을 보고 바로 수정 |
| 꼼수 | 수학 찍기 감지, 레벨 바닥, 유휴 시간 제외 (원글 경험 반영) |
| 기기마다 기록이 따로 | 보호자 모드를 기기별로 확인, 동기화(T14)는 후순위 |
