# Study_Kt 기획서 — 우리 가족 학습 스테이션

> 첫째(초5) + 둘째(초3) + 나(45세)가 **한 기기에서 프로필만 바꿔** 매일 조금씩 공부하는 가족용 학습 웹앱.
> 영감: 에펨코리아 「노트 10+ 로 DeX 기반 AI 학습용 PC/학습 스테이션 만듦」 글과 후속 글.
> 정해진 연산과 영어 미션을 끝내야 유튜브가 풀리는 보상 구조, AI 실시간 영어회화.

---

## 1. 목표

| 대상 | 목표 | 성공 기준 (3개월) |
|---|---|---|
| 첫째 (2015.4생, 초5) | 5학년 연산 완성(분수·소수·약수배수), 영어 단어와 문장 말하기 | 주 5일 이상 미션 완료, 연산 정답률 90%↑ |
| 둘째 (2017.9생, 초3) | 3학년 연산(세 자리 덧뺄셈, 곱셈, 나눗셈), 영어 기초 단어 | 주 5일 이상 미션 완료, 단어 100개 암기 |
| 나 (만 45세) | 비즈니스 영어회화, AI 지식, 독서 정리 | 비즈니스 문장 200개 섀도잉, 월 2권 독서노트 |
| 나 (관리자) | 아이들 진도 확인, 보상 관리 | 대시보드를 주 1회 확인 |

**원칙**
1. **매일 15~20분 안에 끝나는 양.** 많이 시키기보다 매일 하게 만든다.
2. **끝내면 보상.** 미션을 다 하면 "유튜브 30분 이용권" 같은 쿠폰이 생긴다.
3. **틀린 건 다시 나온다.** 오답노트와 간격 반복(SRS)으로 자동 복습한다.
4. **AI 없이도 돌아간다.** 1단계는 무료와 오프라인으로 동작하게 하고, AI는 2단계 이후에 붙인다.

```
[프로필 선택]  🦁 첫째 / 🐰 둘째 / 🦉 나
      │
      ▼
[오늘의 미션] ── 진행률 바, 연속 학습일(🔥), 별 개수
  ├─ 🔢 연산 20문제     → 오답은 오답노트로 이동
  ├─ 🔤 영어 단어 10개   → 간격 반복(Leitner 5단계)
  ├─ 🗣️ 따라 말하기 5문장 → TTS 듣기, 음성인식 채점
  └─ 📚 독서노트 (선택)
      │
      ▼  모든 미션 완료
[🎁 보상 쿠폰 획득]  "유튜브 30분 이용권" → 보호자가 '사용 처리'

[보호자 모드] (PIN 잠금)
  ├─ 아이별 대시보드: 7일 학습 기록, 정답률, 자주 틀리는 유형
  ├─ 미션 설정: 문제 수, 연산 단원 on/off, 보상 시간
  ├─ 쿠폰 관리
  └─ 데이터 백업/복원 (JSON)
```

## 3. 학습 콘텐츠 설계

### 3-1. 연산 (2022 개정 교육과정 기준, 문제 자동 생성)

10월 기준으로 2학기 단원을 기본으로 켜고, 1학기 단원은 복습용으로 켠다.

**3학년 (둘째)**
| 단원 | 유형 | 학기 |
|---|---|---|
| 덧셈과 뺄셈 | 세 자리 수 덧셈, 뺄셈 (받아올림, 받아내림) | 3-1 |
| 나눗셈 | 곱셈구구 범위의 나눗셈 | 3-1 |
| 곱셈 | 두 자리 × 한 자리 | 3-1 |
| 곱셈 | 세 자리 × 한 자리, 두 자리 × 두 자리 | 3-2 |
| 나눗셈 | 두 자리 ÷ 한 자리 (나머지 있음) | 3-2 |

**5학년 (첫째)**
| 단원 | 유형 | 학기 |
|---|---|---|
| 자연수의 혼합 계산 | 괄호와 사칙연산 순서 | 5-1 |
| 약수와 배수 | 최대공약수, 최소공배수 | 5-1 |
| 약분과 통분 | 기약분수로 나타내기 | 5-1 |
| 분수의 덧셈과 뺄셈 | 분모가 다른 분수 | 5-1 |
| 수의 범위와 어림하기 | 올림, 버림, 반올림 | 5-2 |
| 분수의 곱셈 | 분수 × 분수, 자연수 × 분수 | 5-2 |
| 소수의 곱셈 | 소수 × 자연수, 소수 × 소수 | 5-2 |
| 평균 | 자료의 평균 | 5-2 |

- 답 입력 방식은 정수, 소수, 분수(자연수, 분자, 분모 칸), 몫과 나머지로 나눈다.
- 틀린 문제는 **오답노트**에 저장하고, 다음 연산 세션 앞부분에 다시 낸다. 맞히면 오답노트에서 빠진다.

### 3-2. 영어 단어 (간격 반복)
- 덱: `초3 기초 단어`, `초5 단어`, `비즈니스·AI 표현`(보호자용)
- 카드마다 듣기(TTS), 뜻 4지선다, 듣고 고르기를 섞어서 낸다.
- Leitner 5단계: 맞히면 다음 상자로(복습 간격 1, 3, 7, 14, 30일), 틀리면 1단계로 돌아간다.

### 3-3. 따라 말하기 (섀도잉)
- 브라우저 TTS로 문장을 들려주고, 음성인식(Web Speech API)으로 말한 문장을 받아 단어 단위로 채점한다.
- 아이들은 교과서 수준의 생활 문장, 보호자는 회의, 이메일, 협상, 프레젠테이션, 스몰토크, AI 관련 비즈니스 문장을 쓴다.
- 음성인식을 지원하지 않는 브라우저에서는 "말했어요" 버튼으로 자가 체크한다.

### 3-4. 독서·지식 노트
- 책 제목, 핵심 요약, 기억할 질문/답(Q&A 카드)을 기록한다.
- Q&A 카드는 간격 반복 복습에 들어간다.
- 아이들은 독서록으로 쓸 수 있다(선택 미션).

## 4. 동기부여 시스템

| 장치 | 내용 |
|---|---|
| ⭐ 별 | 정답 1개마다 별 1개. 누적 표시 |
| 🔥 연속 학습일 | 하루 미션을 모두 끝내면 +1, 하루 빠지면 0 |
| 🎁 보상 쿠폰 | 하루 미션을 모두 끝내면 쿠폰 1장 (기본: 유튜브 30분). 보호자가 내용과 시간을 바꿀 수 있음 |
| 📅 스탬프 달력 | 미션을 완료한 날에 도장 |
| 🏆 주간 보너스 | 주 5일 완료 시 보너스 쿠폰 (2단계) |

> 원글처럼 유튜브를 **기기 차원에서** 잠그려면 웹앱만으로는 안 된다.
> Google Family Link나 iOS 스크린타임으로 유튜브를 기본 차단해 두고, 쿠폰이 생기면 보호자가 풀어주는 운영 방식을 권장한다(4단계에서 자동화 검토).

## 5. 기술 설계

| 항목 | 선택 | 이유 |
|---|---|---|
| 형태 | 웹앱 + PWA | 태블릿, PC, 폰 어디서나 실행되고 홈 화면에 설치 가능, 오프라인 동작 |
| 프레임워크 | Vite + React + TypeScript | 빠른 개발, 타입 안정성 |
| 저장소 | `localStorage` (1단계) → 클라우드 동기화 (2단계) | 1단계는 서버와 비용 없이 시작 |
| 음성 | Web Speech API (TTS + 음성인식) | 무료, 설치 불필요 |
| 테스트 | Vitest | 문제 생성기, 채점, SRS 로직 검증 |
| 배포 | GitHub Pages (GitHub Actions) | 무료, push하면 자동 배포 |
| AI (2단계~) | OpenAI API + 서버리스 프록시 (Cloudflare Workers) | 저렴한 소형 모델(mini, nano 계열)이 많음. API 키는 프록시에만 두고, 회화와 생성 모델을 환경변수로 따로 지정. 제공사 어댑터 구조라 나중에 교체 가능 |

### 폴더 구조
```
src/
  types.ts                  공통 타입
  store/                    상태 관리와 저장 (localStorage, 스키마 버전)
  lib/                      날짜, 음성, 문장 유사도, SRS, 보상 로직
  content/math/             학년별 연산 문제 생성기와 분수 유틸
  content/english/          단어 덱, 말하기 문장
  pages/                    화면 (프로필, 홈, 연산, 단어, 말하기, 독서, 보호자)
  components/               공통 UI (분수 입력 등)
```

## 8. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 아이가 금방 질림 | 하루 분량을 작게 유지, 보상 즉시 지급, 아이가 고른 아바타와 테마 |
| 기기마다 데이터가 따로 저장됨 | 1단계는 "한 기기 고정 사용"을 권장, JSON 백업 제공, 2단계에서 동기화 |
| 음성인식 품질과 브라우저 지원 차이 | Chrome(안드로이드/PC) 권장, 미지원 시 자가 체크로 대체 |
| AI 비용 증가 | 소형 모델 기본, 답장 길이 상한, OpenAI 프로젝트 월 예산 한도, 프록시에서 프로필별, 가족 전체 하루 요청 상한, 용도별 모델 분리 |
| AI가 계산을 틀림 | 문장제의 숫자와 정답은 코드가 정하고 AI는 이야기만 씀, 숫자 검증 실패 시 원래 문제로 대체 |
| 아이 대화 안전 | 프롬프트는 서버(Worker)에만 두고 앱은 시나리오 id만 보냄, 나이에 맞는 주제와 개인정보 질문 금지 지침, 아이 메시지는 모더레이션 API로 먼저 검사 |
| 아이 데이터 보호 | 1단계는 기기 밖으로 데이터가 나가지 않음, 2단계 동기화는 가족 계정 인증 |
