# T08b 과학 문제 원고 검토

**보호자 확인 필요: 과학 문제 100개.** 문제·정답·해설·관련 실험을 `src/content/science/questions.ts`에서 직접 읽고 승인한다. 자동 검사는 형식·연결·분포를 확인하며 과학적 정확성 승인을 대신하지 않는다.

## 현재 단원명 확인 (2026-10-07)

2022 개정 교육과정을 반영한 비상교육 공식 교재의 공개 목차를 확인했다. 초5 2학기는 해당 교과서 자습서 목차와도 대조했다. 출판사별 단원 순서는 다를 수 있으며, 가족이 쓰는 교과서 출판사는 아직 확인하지 않았다.

| 학년·학기 | 공식 출판사 공개 목차 | 사용한 단원명 |
|---|---|---|
| 초3 1학기 | [오투 초등 과학 3-1 (22개정)](https://book.visang.com/books/info/5444) | 힘과 우리 생활, 동물의 생활, 식물의 생활, 생물의 한살이 |
| 초3 2학기 | [오투 초등 과학 3-2 (22개정)](https://book.visang.com/books/info/5743) | 물체와 물질, 지구와 바다, 소리의 성질, 감염병과 건강한 생활 |
| 초5 1학기 | [오투 초등 과학 5-1 (22개정)](https://book.visang.com/books/info/5836) | 지층과 화석, 빛의 성질, 용해와 용액, 우리 몸의 구조와 기능 |

명세의 예시 단원명에는 이전 교육과정 내용이 있어 현재 목차를 우선했다. 초3은 40문제 중 28문제, 초5는 40문제 중 24문제를 2학기 단원에 배치했다. 기존 실험에 연결하는 초5 운동·산염기 4문제는 현재 학년의 교과 단원으로 표시하지 않고 **생활 속 과학 · 초5 보충**으로 표시한다. 기존 실험의 `curriculum` 필드는 역사적 원고 그대로 유지하며 새 문제의 단원 표시에 사용하지 않는다.

## 원고 작성 기준

- 공통·초3 질문은 두 문장 이내, 해설은 모든 문제에서 두 문장이다.
- 객관식 정답 위치는 공통/각 학년 안에서 고르게 배치했다. 화면에서 보기 순서를 바꾸지 않는다.
- 초3의 섬·물고기·곤충 상황과 초5의 만들기·장애물 상황은 실제 현상을 다룬다. 게임 이름과 게임 규칙은 쓰지 않았다.
- 뜨고 가라앉기는 무게만으로 설명하지 않고 전체 밀도와 물의 밀도로 설명했다.
- 컵 두드리기와 컵 입구 불기의 높낮이를 혼동하지 않도록 ‘두드릴 때’를 명시했다.
- 구름·안개·눈에 보이지 않는 수증기를 구분했다. 용해의 빠르기와 최대로 녹는 양도 구분했다.
- 모든 기존 실험에 관련 문제를 하나씩 연결했다. 준비·행동·주의 문구는 기존 승인 대상 원고를 보존했다.

보호자는 과학적 정확성, 아이가 읽을 수 있는 어휘, 실제 교과서와의 단원 대응을 확인한다. 실제 Fold4 + DeX 물리 키보드 사용과 집에서 하는 실험은 별도 확인이 필요하다.
