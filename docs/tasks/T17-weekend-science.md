# T17 — 과학 실험 미션은 주말에만 (요일별 미션)

- 상태: 준비됨
- 단계: 4 (T08 후속)
- 선행 작업: T08
- 예상 분량: 반나절

## 목표
과학 실험 카드(T08)가 **토요일과 일요일에만 하루 미션**이 된다. 평일에는 실험을 못 해도 그날 미션 완료와 연속 학습일에 영향이 없고, 아이가 원하면 평일에도 실험하고 도감을 볼 수 있다.

## 배경
- 실험 카드는 대부분 보호자가 함께해야 한다. 평일에는 보호자 시간이 부족해 미션을 못 끝내는 날이 생기고, 그러면 연속 학습일이 끊긴다.
- 보호자 결정 (2026-10-07): **과학 미션은 주말에만**.
- 요일 설정은 다른 미션에도 쓸 수 있게 일반 기능으로 만든다(예: 나중에 독서를 주말만).

## 범위
**포함**
- 미션에 요일 설정 추가. 과학 미션 기본값은 토·일.
- 하루 미션 목록, 완료 판정, 진행률이 그날 요일을 따른다.
- 평일 홈 화면: 미션 목록 아래에 "🔬 실험 도감" 카드(자유 놀이). 누르면 도감으로 가고, 거기서 "오늘의 실험 해 보기"로 평일에도 실험할 수 있다. 이때 도감 기록, 배지는 그대로 생기지만 미션 완료에는 들어가지 않는다.
- 주말 홈 화면: 지금처럼 "🔬 오늘의 실험" 미션.
- 보호자 모드 → 아이 설정: 미션마다 요일 선택 칩(일 월 화 수 목 금 토). 과학 미션 기본은 토·일만 선택, 다른 미션은 모두 선택.

**제외**
- 공휴일 자동 인식 (공휴일에도 하고 싶으면 보호자가 요일 칩을 잠깐 바꾼다)
- 미션별 시간대 설정, 알림

## 설계
### 데이터 모델
`src/types.ts`
```ts
export interface MissionConfig {
  type: MissionType;
  enabled: boolean;
  target: number;
  /** 미션을 하는 요일 (0=일 … 6=토). 없으면 매일. */
  days?: number[];
}
```
- 선택 필드라 `version`은 2 그대로.
- `store/defaults.ts`: 두 아이의 `science` 미션에 `days: [0, 6]`.
- `normalizeState()`: `days`가 배열이 아니면 지운다(매일). 0~6 정수만 남기고 중복 제거, 정렬. 빈 배열이 되면 지운다(매일). 기존 저장 데이터의 `science` 미션에 `days`가 없으면 **한 번만** `[0, 6]`을 넣는다. 보호자가 나중에 모든 요일을 고르면 `days`를 빼서 저장하므로 다시 덮어쓰지 않는다. 이를 구분하려고 `ProfileSettings.scienceDaysMigrated?: true` 표시를 둔다.

### 순수 로직 `src/lib/progress.ts`
```ts
export interface ProgressOptions { aiReady: boolean; date?: string } // date: 'YYYY-MM-DD'
/** date가 있으면 그 요일에 하는 미션만. date가 없으면 요일 무시(기존 동작). */
export function enabledMissions(settings: ProfileSettings, options: ProgressOptions): MissionConfig[];
/** 'YYYY-MM-DD' → 0~6. 시간대 영향을 받지 않게 문자열을 직접 풀어서 계산한다. */
export function weekdayOf(date: string): number;
```
- `isDayComplete(day, settings, options)`와 `dayRatio(...)`는 `options.date ?? day?.date`로 요일을 정한다.
- `applyProgress()`와 연속 학습일 계산이 이 함수를 거치므로 따로 바꿀 필요가 없는지 확인하고, 다른 곳에서 미션 목록을 직접 거르는 코드가 있으면 이 함수로 모은다.
- 그날 할 미션이 하나도 없으면(모든 미션이 요일 밖) 기존과 같이 완료가 아니다.

### 화면
- `Home.tsx`: `enabledMissions(settings, { aiReady: true, date: today() })`.
- 평일이고 과학 미션이 켜져 있으면 "🔬 실험 도감" 자유 카드 표시. 문구: "실험은 주말 미션이에요. 하고 싶으면 지금 해도 돼요!"
- 평일 실험 결과도 `ProfileData.science.done`에 저장하고 도감, 배지에 반영한다. `DayLog.progress.science`도 올려도 되지만 그날 미션 목록에 없으므로 완료 판정에 영향이 없어야 한다.
- 보호자 모드 요일 칩: 큰 터치 영역(최소 44px), 선택된 칩은 `--primary`. 모두 끄려고 하면 "최소 하루는 골라 주세요"로 막는다(미션을 끄려면 기존 켜기/끄기 스위치 사용).

## 수용 기준
- [ ] 토요일과 일요일에는 두 아이 홈에 "🔬 오늘의 실험" 미션이 있고, 끝내야 하루 미션이 완료된다.
- [ ] 월~금에는 과학이 미션 목록에 없고, 나머지 미션만 끝내도 하루 완료, 별, 연속 학습일이 정상 처리된다.
- [ ] 평일에도 "🔬 실험 도감"에서 실험할 수 있고, 카드가 도감에 들어가고 배지가 생긴다.
- [ ] 보호자가 요일 칩을 바꾸면 다음 화면부터 반영되고, 모든 요일을 고르면 매일 미션이 된다.
- [ ] 기존 데이터(과학 미션에 `days` 없음)를 열면 토·일로 한 번 바뀌고, 보호자가 바꾼 설정은 다시 덮어쓰지 않는다.
- [ ] `weekdayOf`, 요일 반영 `enabledMissions`/`isDayComplete`/`dayRatio`, `normalizeState` 요일 정리 단위 테스트가 있다(평일·주말, 잘못된 `days` 값, 빈 배열, 중복).
- [ ] `npm run lint && npm run typecheck && npm test && npm run build` 통과

## 테스트
- 단위: 2026-10-10(토), 2026-10-12(월) 같은 고정 날짜로 판정 확인. 연속 학습일이 금요일 → 토요일로 이어지는지.
- 직접: 기기 날짜를 바꾸지 말고, 보호자 모드에서 오늘 요일 칩을 켜고 끄며 홈 변화를 확인.

## 리뷰 포인트
- 요일 계산이 시간대(UTC와 한국 시간) 때문에 하루 밀리지 않는지.
- 연속 학습일 계산이 과거 날짜의 요일 기준으로 판정되는지(오늘 요일로 과거를 판정하면 안 됨).
- 마이그레이션 표시가 백업 내보내기/가져오기 뒤에도 유지되는지.
