# T03 — AI 영어회화: 아이용 상황극

- 상태: 준비됨
- 단계: 2
- 선행 작업: T02
- 예상 분량: 하루

## 목표
첫째와 둘째가 상황(식당 주문, 새 친구 사귀기, 길 묻기 등)을 골라 AI 캐릭터와 **음성으로** 짧게 영어 대화를 하고, 끝나면 칭찬과 고칠 표현을 받는다. 이 대화가 하루 미션 하나("AI 회화")로 잡힌다.

## 배경
원글의 핵심이 "AI와 실시간 영어회화 최대 30분, 끝나야 유튜브"였다. 1단계의 따라 말하기는 정해진 문장만 쓰므로, 실제로 주고받는 대화를 더한다.

## 범위
**포함**
- 새 미션 타입 `talk` (`MissionType`에 추가). 목표 단위는 **턴 수**(아이가 말한 횟수). 기본값: 초3 6턴, 초5 10턴, 보호자는 끔.
- 시나리오 선택 화면 → 대화 화면 → 피드백 화면
- 시나리오는 Worker의 `prompts.ts`에 정의하고, 앱은 같은 id 목록과 표시용 정보(제목, 이모지, 한국어 설명)를 `src/content/english/talkScenarios.ts`에 둔다.
- 음성 입력: 기존 `listenOnce()` 사용. 인식 결과를 화면에 보여 주고 **아이가 "보내기"를 눌러야 전송**(잘못 인식된 문장을 고칠 기회).
- 음성 출력: AI 답장을 `speak()`로 읽어 줌. 스트리밍 중에는 글자가 나타나고, 문장이 끝나면 읽기 시작.
- 음성 인식 미지원 브라우저: 텍스트 입력으로 대체.
- 막혔을 때 버튼: "힌트 보기"(AI 마지막 질문에 답할 수 있는 예시 문장 2개, 한국어 뜻 포함)와 "한국어로 물어보기"(아이가 한국어로 말해도 AI가 쉬운 영어로 바꿔 알려 줌)
- 종료: 목표 턴 수에 도달하면 "대화 마치기" 버튼 강조. 마치면 `/api/generate` `kind: 'talk-feedback'`으로 피드백 요청
- 피드백: 잘한 문장 2개, 고칠 표현 최대 3개(아이 문장 → 고친 문장 → 한국어 설명), 새로 배운 단어 최대 3개. **고친 문장은 그 자리에서 "따라 말하기"로 연습 가능**
- 대화 기록 저장: `ProfileData.talks: TalkLog[]` (최근 30개만 유지)

**제외**
- 실시간 양방향 음성 스트리밍(Realtime API 류)
- 발음 점수 평가
- 보호자용 비즈니스 롤플레이 (T04)

## 설계

### 데이터 모델
```ts
type MissionType = 'math' | 'vocab' | 'speaking' | 'reading' | 'talk';

interface TalkTurn { role: 'user' | 'assistant'; text: string }
interface TalkFeedback {
  praise: string[];                                        // 잘한 문장 (영어 원문)
  fixes: { said: string; better: string; tip: string }[];  // tip은 한국어
  newWords: { en: string; ko: string }[];
}
interface TalkLog {
  id: string; date: string; scenarioId: string;
  turns: TalkTurn[]; feedback?: TalkFeedback;
}
// ProfileData에 talks: TalkLog[] 추가 (normalizeState에서 기본값 [])
// ProfileSettings.missions에 talk 항목 추가 (기존 저장 데이터에도 끼워 넣기)
```

### 진행 기록
- 아이가 한 턴을 보낼 때마다 `applyProgress(d, settings, today, { type: 'talk' })`.
- 별은 피드백 화면에서 한 번: `correct: praise.length + 1`(참여 보너스), `total: 0`으로 정답률에는 영향 없음.

### 시나리오 (최소 6개)
| id | 수준 | 상황 | AI 역할 |
|---|---|---|---|
| `g3-new-friend` | 초3 | 놀이터에서 새 친구 만나기 | 같은 나이 친구 Sam |
| `g3-pet-shop` | 초3 | 애완동물 가게 구경 | 가게 주인 |
| `g3-favorites` | 초3 | 좋아하는 것 이야기 | 외국인 선생님 |
| `g5-restaurant` | 초5 | 식당에서 주문하기 | 종업원 |
| `g5-directions` | 초5 | 길 묻고 답하기 | 여행 온 관광객 |
| `g5-weekend` | 초5 | 지난 주말 이야기 (과거형) | 외국인 친구 |

### 아이용 시스템 프롬프트 요구사항 (Worker `prompts.ts`)
- 학년별 어휘 수준: 초3은 1~6단어 문장과 현재형 위주, 초5는 1~2문장과 과거형, 조동사까지
- 한 번에 **질문 하나**, 답장은 최대 2문장
- 틀린 문법을 직접 지적하지 말고 올바른 형태로 자연스럽게 되받아 말하기(recast)
- 아이가 한국어로 말하면 쉬운 영어 문장을 알려 주고 따라 해 보라고 권하기
- 안전: 나이에 맞지 않는 주제, 개인정보(실제 이름, 학교, 주소, 연락처)는 묻지 않고, 아이가 말하면 다른 화제로 부드럽게 돌리기
- 시나리오 밖으로 길게 벗어나면 상황으로 돌아오기

## 수용 기준
- [ ] 홈 화면에 "🤖 AI 회화" 미션이 보이고, 턴 수만큼 진행률이 오른다. 프록시 설정이 없으면 "보호자에게 AI 연결을 부탁하세요" 안내와 함께 미션이 자동 완료 조건에서 빠진다(설정 없이 하루 미션 완료가 막히면 안 됨).
- [ ] 아이가 말한 문장이 화면에 나오고, 고친 뒤 보낼 수 있다.
- [ ] AI 답장이 글자로 스트리밍되고 소리로 읽힌다. "다시 듣기" 버튼이 있다.
- [ ] 힌트 보기, 한국어로 물어보기가 동작한다.
- [ ] 네트워크 오류, 429(오늘 사용량 초과), 안전 차단(`unsafe`)에서 아이가 이해할 수 있는 문구가 나오고 홈으로 돌아갈 수 있다.
- [ ] 피드백이 스키마대로 오고, 고친 문장을 따라 말하기로 연습할 수 있다.
- [ ] 기존 사용자 데이터(talk 미션이 없는 설정)를 불러와도 깨지지 않는다(테스트).
- [ ] 보호자 현황에 최근 대화 목록(날짜, 시나리오, 턴 수, 피드백 요약)이 보인다.
- [ ] `npm run typecheck && npm test && npm run build` 통과

## 테스트
- `normalizeState`가 talk 미션과 `talks`를 채우는지
- 턴 수 진행과 미션 완료 판정
- 피드백 JSON 검증 함수 (필드 누락, 빈 배열)
- 직접: 태블릿 Chrome에서 시나리오 2개 끝까지 대화

## 리뷰 포인트
- 프롬프트의 안전 지침, 개인정보를 Worker로 보내지 않는지(프로필 이름 대신 id와 학년만)
- 음성 인식 결과를 보내기 전에 확인하는 흐름이 아이에게 번거롭지 않은지
- 미션 완료 조건이 AI 미설정 상태에서도 막히지 않는지
