# T07 — 오늘의 문제 게임과 형제 대결

- 상태: 준비됨
- 단계: 3
- 선행 작업: T05
- 예상 분량: 하루

## 목표
수학 미션을 끝내면 **오늘 푼 문제로 만든 낚시 게임**이 열린다. 형제가 같은 기기에서 번갈아 대결하고, 이긴 아이가 다음 게임 선택권을 갖는다.

## 배경
원글: 오늘 푼 문제가 물고기로 나오는 낚시 게임, 형제 대결에서 이긴 아이가 다음 게임 선택권 → 둘 다 수학을 열심히 했다.

## 범위
**포함**
- 🎣 낚시 게임 (DOM과 CSS 애니메이션 또는 Canvas, 외부 게임 라이브러리 없이)
  - 물고기마다 오늘 푼 문제가 붙어 있다. **오늘 틀린 문제는 금빛 물고기**(점수 3배)
  - 물고기를 누르면 문제가 뜨고, `NumberPad`로 맞히면 잡힌다. 틀리면 물고기가 도망간다(다시 나옴).
  - 한 판 90초, 점수 = 잡은 물고기 점수 합
  - 오늘 수학 미션을 끝냈을 때만 열림. 하루 플레이 횟수 상한(보호자 설정, 기본 3판)
- ⚔️ 형제 대결 모드
  - 같은 기기에서 첫째와 둘째가 번갈아 한 판씩. 문제는 **각자 자기 레벨**(T05)에서 같은 시드로 10문제 생성
  - 점수 = 정답 수 × 10 + 남은 시간 보너스. 레벨 차이가 나도 공정하도록 각자 레벨 문제를 푼다
  - 이긴 아이에게 "👑 다음 게임 선택권" 배지가 다음 날까지 홈에 표시
- 오늘의 미션 완료 화면에 "🎣 게임 열림!" 버튼

**제외**
- 다른 게임 종류(나중에 추가할 수 있게 게임 목록 구조만 만든다), 기기 간 대결

## 설계
- 오늘 문제 모으기: T05의 `DayLog.mathAttempts`에 문제 본문이 없으면 문제(`MathProblem`)도 함께 저장하도록 확장
- 게임 기록: `ProfileData.games: { date: string; game: 'fishing' | 'duel'; score: number }[]` (최근 60개), `ProfileData.crownUntil?: string`
- 게임 상태 로직(물고기 생성, 점수 계산, 대결 승자 판정)은 순수 함수로 분리해 테스트
- 낚시 게임은 보상이라 별과 미션 진행에는 영향 없음(게임으로 별을 모으는 꼼수 방지)

## 수용 기준
- [ ] 수학 미션 전에는 게임이 잠겨 있고, 끝나면 열린다.
- [ ] 물고기에 오늘 푼 문제가 나오고, 오늘 틀린 문제는 금빛 물고기다.
- [ ] 하루 플레이 횟수 상한이 지켜진다.
- [ ] 대결에서 두 아이가 각자 레벨 문제를 풀고, 승자에게 왕관 배지가 다음 날까지 보인다.
- [ ] 게임 점수가 별이나 미션 진행에 영향을 주지 않는다.
- [ ] DeX 큰 화면과 375px 폭에서 플레이 가능, 애니메이션이 느린 기기에서도 끊기지 않는다(`requestAnimationFrame`, 물고기 최대 8마리).
- [ ] `npm run typecheck && npm test && npm run build` 통과
