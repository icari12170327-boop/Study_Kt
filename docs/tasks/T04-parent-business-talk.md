# T04 — 보호자 비즈니스 프리토킹과 "내 표현"

- 상태: 준비됨
- 단계: 2
- 선행 작업: T02, T03 (대화 화면과 realtime 도우미 재사용)
- 예상 분량: 하루

## 목표
보호자가 회의, 협상, 스몰토크 같은 비즈니스 상황을 AI 상대와 **음성으로 자유롭게** 연습하고, 끝나면 더 자연스러운 표현을 받아 **"내 표현"** 카드로 저장해 간격 반복으로 복습한다.

## 범위
**포함**
- 보호자 `talk` 미션 켜기(기본 15분), 홈에 "💼 비즈니스 프리토킹"
- 상황 선택(아래 6개 + "자유 대화: AI·테크 업계 동료와 수다"), Worker `mode: 'biz-talk'`, `scenarioId`
- T03 대화 화면을 재사용하되 보호자용 차이: 자막 가림 없음, "방금 내 말 더 자연스럽게" 버튼(마지막 내 발화를 `kind: 'biz-feedback'`의 짧은 모드로 보내 대안 표현 2개)
- 대화 끝 피드백 `kind: 'biz-feedback'`: 전체 평가 한 줄(한국어), 고칠 표현 최대 5개(`said`, `better`, `why`), 다음에 써 볼 핵심 표현 3개
- "내 표현에 저장" → 사용자 덱 `my-phrases`. 단어 세션과 따라 말하기 세션에 등장
- 보호자 대화 기록은 T03 기록 화면 재사용

| scenarioId | 상황 | AI 역할 |
|---|---|---|
| `biz-standup` | 주간 업무 공유 회의 | 해외 팀 매니저 |
| `biz-negotiation` | 납품 단가 협상 | 공급업체 영업 담당 |
| `biz-presentation-qa` | 발표 후 질의응답 | 까다로운 임원 |
| `biz-ai-adoption` | 사내 AI 도입 논의 | 회의적인 동료 |
| `biz-smalltalk` | 해외 출장 첫 미팅 전 스몰토크 | 거래처 담당자 |
| `biz-escalation` | 문제 상황 보고 | 고객사 담당자 |
| `biz-free` | AI, 테크 이야기 자유 대화 | 업계 동료 |

**제외**
- 이메일 첨삭, 발음 평가

## 설계
- 사용자 카드: `ProfileData.customCards: { id; en; ko; source: string; createdAt: string }[]`
- 덱 조회 함수 `getVocabCards(deckId, data)`로 정적 덱과 `my-phrases`를 같은 방식으로 다룬다. `buildVocabSession`과 따라 말하기가 이 함수를 쓰도록 바꾼다. 카드가 4장 미만이면 오답 보기를 다른 덱에서 채운다.
- SRS 키 규칙 유지: `vocab:my-phrases:<id>`, `speak:my-phrases:<id>`. 카드 삭제 시 SRS 키도 삭제.
- Worker 지시문(`biz-talk`) 요구사항: 역할을 일관되게 연기, 답장 2~4문장, 짧은 답에는 구체적으로 되묻기, **대화 중에는 교정하지 않고** 피드백 때 모아서, 상대가 한국어로 막히면 "You could say …"로 한 번 도와주기.

## 수용 기준
- [ ] 7개 상황 중 하나를 골라 음성 대화를 하고, 1분마다 미션 진행이 오른다.
- [ ] "더 자연스럽게" 버튼이 대화를 끊지 않고 대안 표현을 보여 준다.
- [ ] 피드백 표현을 "내 표현"에 저장하면 다음 단어 세션과 따라 말하기에 나온다. 보호자 설정에서 덱 켜기, 끄기, 카드 삭제 가능.
- [ ] 아이 프로필에는 비즈니스 상황이 보이지 않는다.
- [ ] 백업과 복원에 `customCards` 포함, `normalizeState` 기본값.
- [ ] `npm run typecheck && npm test && npm run build` 통과
