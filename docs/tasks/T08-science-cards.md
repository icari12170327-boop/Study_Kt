# T08 — 과학 실험 카드, 도감, 배지, 캐릭터 옷차림

- 상태: 준비됨 (둘째가 과학을 좋아하는지 먼저 확인. 아니면 우선순위 낮춤)
- 단계: 4
- 선행 작업: 없음
- 예상 분량: 이틀 (화면 1일, 실험 카드 30장 작성 1일)

## 목표
매일 실험 카드 한 장이 나온다. 아이가 결과를 예상하고, 보호자와 집에서 실험하고, 결과를 기록하면 도감에 카드가 모이고 배지가 생긴다. 실험 중에 영어 한두 문장을 자연스럽게 따라 말한다. "공부해"가 아니라 "오늘은 뭐 실험해?"가 되게 한다.

## 범위
**포함**
- 미션 타입 `science` (단위: 장, 기본 둘째 1장 켬, 첫째 끔)
- 실험 카드 데이터 `src/content/science/cards.ts` — **첫 배포 30장** (목표 80장)
- 오늘의 카드 선택: 아직 안 한 카드 중 날짜 시드로 하나. 보호자가 "오늘 다른 카드" 버튼으로 바꿀 수 있음(재료가 없을 때)
- 흐름 화면: 질문 → 예상 고르기 → 준비물 확인 → 단계별 실험(보호자와 함께, 단계마다 "했어요") → 결과 고르기 → 설명 → 영어 문장 따라 말하기(1단계 따라 말하기 화면 재사용, 브라우저 TTS) → 도감에 카드 획득 애니메이션
- 도감 화면: 주제별 칸, 얻은 카드는 색깔, 안 한 카드는 실루엣
- 배지: 주제별 3장, 6장, 10장
- 캐릭터 옷차림: 프로필 아바타에 날짜별로 바뀌는 소품(🎩🧢👓🎀🦺 등) 표시. 순수 함수 `outfitFor(date, profileId)`

**제외**
- 사진 업로드 (기기 저장 공간 문제, 나중에)
- AI 실험 설명 생성

## 설계

### 카드 형식
```ts
interface ScienceCard {
  id: string;                 // 바꾸지 않음 (도감 기록 키)
  topic: 'float-sink' | 'electricity' | 'light' | 'sound' | 'magnet' | 'states' | 'mixing' | 'air' | 'living';
  curriculum?: string;        // 예: '3-1 물질의 성질', '3-2 소리의 성질'
  title: string;              // 예: '물에 뜰까, 가라앉을까?'
  question: string;
  predictions: string[];      // 예상 보기 2~4개
  materials: string[];        // 집에 있는 것만
  steps: string[];            // 3~6단계, 초3이 읽을 수 있는 문장
  result: string;             // 정답 결과 (예상 보기 중 하나와 같은 문자열)
  explain: string;            // 왜 그럴까? 2~3문장
  english: { en: string; ko: string }[]; // 따라 말할 문장 1~2개, 예: 'It floats!'
  safety?: string;            // 보호자 주의 문구
  adultNeeded: boolean;
}
// ProfileData.science: { done: Record<cardId, { date: string; predicted: string; observed: string }> ; badges: string[] }
```

### 첫 30장 주제 (3학년 과학 단원과 연결)
- 뜨고 가라앉기 5장(사과, 동전, 레고, 지우개, 소금물에 달걀) — 3-1 물질의 성질
- 자석 4장(붙는 물건 찾기, 자석 사이 종이, 나침반 만들기, 자석 낚시) — 3-1 자석의 이용
- 소리 4장(고무줄 기타, 컵 전화기, 물 컵 실로폰, 풍선 진동) — 3-2 소리의 성질
- 물질의 상태 4장(얼음 녹이기 경주, 물이 어디로 갔을까, 풍선에 공기 무게, 숟가락 김 서림) — 3-2 물질의 상태
- 빛과 그림자 4장(그림자 길이 바꾸기, 물컵 속 빨대 굴절, 손전등 색 섞기, 무지개 만들기)
- 섞기와 색 4장(물감 섞기, 식용 색소 물 섞기, 기름과 물, 설탕 녹이기)
- 공기와 힘 3장(빨대 공기 로켓, 종이 비행기 접기 비교, 낙하산)
- 정전기와 전기 2장(풍선 정전기, 레몬 전지는 **꼬마전구 대신 LED + 보호자 필수**)

### 안전 원칙 (카드 작성 규칙, 리뷰 필수 항목)
- 불, 가열, 칼, 전기 콘센트, 세제와 표백제 같은 화학약품은 쓰지 않는다.
- 삼킬 수 있는 작은 물건(동전, 자석)은 `adultNeeded: true`와 주의 문구.
- 모든 카드는 PR에서 보호자가 직접 읽고 승인한다(AI 초안 사용 시에도).

## 수용 기준
- [ ] 30장 카드가 형식대로 있고, `result`가 `predictions` 중 하나와 일치한다(테스트).
- [ ] 안전 원칙 금지어(불, 가열, 칼, 콘센트, 표백제 등) 검사 테스트가 있다.
- [ ] 오늘의 카드가 날짜마다 바뀌고, 한 카드는 다시 나오지 않는다(다 하면 처음부터).
- [ ] 실험 흐름 끝에 영어 문장 따라 말하기가 나오고, 도감에 카드가 들어간다.
- [ ] 배지와 캐릭터 옷차림이 보인다.
- [ ] 보호자 현황에 실험한 카드와 아이의 예상과 결과가 보인다.
- [ ] `npm run typecheck && npm test && npm run build` 통과
