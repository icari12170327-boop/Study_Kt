# T08 — 과학 실험 카드 (첫째, 둘째 모두), 도감, 배지, 캐릭터 옷차림

- 상태: 준비됨
- 단계: 4 (보호자 요청으로 두 아이 모두 대상, 우선순위 상향 가능)
- 선행 작업: 없음 (AI 불필요, T02와 병행 가능)
- 예상 분량: 이틀 (화면 1일, 실험 카드 40장 작성 1일)

## 목표
첫째와 둘째 모두 과학에 관심을 갖게 한다. 매일 실험 카드 한 장이 나오고, 아이가 결과를 예상하고, 보호자와 집에서 실험하고, 결과를 기록하면 도감에 카드가 모이고 배지가 생긴다. "공부해"가 아니라 "오늘은 뭐 실험해?"가 되게 한다.

## 범위
**포함**
- 미션 타입 `science` (단위: 장, **첫째와 둘째 모두 기본 1장 켬**)
- 실험 카드 데이터 `src/content/science/cards.ts` — **첫 배포 40장**: 함께용 20장, 초3용 10장, 초5용 10장 (목표 80장)
- 학년별 깊이: 같은 카드라도 초5에게는 **"왜 그럴까?" 생각 질문**과 **변인 바꿔 보기**(예: 물 온도를 바꾸면? 소금을 더 넣으면?)를 추가로 보여 준다.
- **"같이 실험" 모드**: 형제가 같은 날 같은 카드를 고르면 한 번 실험하고 각자 예상과 결과를 기록한다. 예상이 맞은 아이에게 별 보너스. 두 아이 도감에 모두 들어간다.
- 오늘의 카드 선택: 그 아이가 아직 안 한 카드 중 날짜 시드로 하나. 보호자가 "오늘 다른 카드" 버튼으로 바꿀 수 있음(재료가 없을 때)
- 흐름 화면: 질문 → 예상 고르기 → 준비물 확인 → 단계별 실험(보호자와 함께, 단계마다 "했어요") → 결과 고르기 → 설명 → (초5) 생각 질문에 한 줄 답 쓰기 → 도감에 카드 획득 애니메이션
- 도감 화면: 주제별 칸, 얻은 카드는 색깔, 안 한 카드는 실루엣
- 배지: 주제별 3장, 6장, 10장
- 캐릭터 옷차림: 프로필 아바타에 날짜별로 바뀌는 소품(🎩🧢👓🎀🦺 등) 표시. 순수 함수 `outfitFor(date, profileId)`
- **AI 친구와 연결 (T03이 있으면)**: 오늘 한 실험 제목을 AI 친구 대화의 주제 칩에 넣는다("Today I made a lemon battery!"). 영어 공부가 아니라 자랑할 거리로.

**제외**
- 카드 안의 영어 따라 말하기 (영어 단어 공부는 학원에서 하므로 넣지 않는다. 영어는 AI 친구 대화에서만)
- 사진 업로드 (기기 저장 공간 문제, 나중에)
- AI 실험 설명 생성

## 설계

### 카드 형식
```ts
interface ScienceCard {
  id: string;                 // 바꾸지 않음 (도감 기록 키)
  audience: 'both' | 'g3' | 'g5';
  topic: 'float-sink' | 'electricity' | 'light' | 'sound' | 'magnet' | 'states'
       | 'mixing' | 'air' | 'living' | 'heat' | 'weather' | 'motion' | 'acid-base' | 'space';
  curriculum?: string;        // 예: '3-1 물질의 성질', '5학년 용해와 용액' (교과서 단원명은 작성 시 확인)
  title: string;              // 예: '물에 뜰까, 가라앉을까?'
  question: string;
  predictions: string[];      // 예상 보기 2~4개
  materials: string[];        // 집에 있는 것만
  steps: string[];            // 3~6단계, 초3이 읽을 수 있는 문장
  result: string;             // 정답 결과 (예상 보기 중 하나와 같은 문자열)
  explain: string;            // 왜 그럴까? 2~3문장 (초3 수준)
  deeper?: {                  // 초5에게만 추가로 보여 줌
    think: string;            // 생각 질문, 예: '소금물에서는 왜 달걀이 뜰까?'
    vary: string;             // 변인 바꿔 보기 제안
    explain: string;          // 조금 더 깊은 설명
  };
  safety?: string;            // 보호자 주의 문구
  adultNeeded: boolean;
}

// }
```

### 첫 40장 주제
**함께용 20장** (`audience: 'both'`, 초5는 `deeper` 포함)
- 뜨고 가라앉기 4장(사과, 동전, 레고, 소금물에 달걀)
- 자석 3장(붙는 물건 찾기, 자석 사이 종이 몇 장까지, 나침반 만들기)
- 소리 3장(고무줄 기타, 컵 전화기, 물 컵 실로폰)
- 빛과 그림자 3장(그림자 길이 바꾸기, 물컵 속 빨대 굴절, 무지개 만들기)
- 공기와 힘 3장(빨대 공기 로켓, 낙하산, 종이 비행기 비교)
- 정전기와 전기 2장(풍선 정전기, 레몬 전지 + LED, 보호자 필수)
- 섞기 2장(기름과 물, 식용 색소 물 섞기)

**초3용 10장** (3학년 단원: 물질의 성질, 동물의 생활, 물질의 상태 등)
- 얼음 녹이기 경주, 물이 어디로 갔을까(증발), 숟가락 김 서림, 풍선에 공기 넣고 무게 비교, 물감 섞기, 설탕 녹이기, 개미 관찰, 고무와 나무 구부려 보기, 휴지 물 타고 올라가기, 종이컵 무게 버티기

**초5용 10장** (5학년 단원 예: 온도와 열, 용해와 용액, 날씨, 물체의 운동, 산과 염기 — 작성 시 교과서 확인)
- 숟가락 재질별 열 전달 비교(따뜻한 물, 손으로 만질 수 있는 온도), 각설탕 녹는 속도와 온도, 소금 몇 숟가락까지 녹을까(포화), 페트병 구름 만들기, 장난감 자동차 속력 재기(거리와 시간), 경사면 기울기와 속력, 양배추 즙 지시약으로 식초와 베이킹소다 구별, 식초 + 베이킹소다 풍선 부풀리기, 그림자 시계(해의 움직임), 달 모양 관찰 기록(일주일)

### 안전 원칙 (카드 작성 규칙, 리뷰 필수 항목)
- 불, 끓는 물, 칼, 전기 콘센트, 세제와 표백제 같은 화학약품은 쓰지 않는다. **허용되는 부엌 재료**: 식초, 베이킹소다, 소금, 설탕, 식용 색소, 양배추.
- "따뜻한 물"은 손으로 만질 수 있는 수돗물 온도까지만, `adultNeeded: true`.
- 삼킬 수 있는 작은 물건(동전, 자석)은 `adultNeeded: true`와 주의 문구.
- 모든 카드는 PR에서 보호자가 직접 읽고 승인한다(AI 초안 사용 시에도).

## 수용 기준
- [ ] 40장 카드가 형식대로 있고, `result`가 `predictions` 중 하나와 일치한다. `audience: 'both'`와 `'g5'` 카드는 모두 `deeper`가 있다(테스트).
- [ ] 안전 원칙 금지어(불, 끓는, 가열, 칼, 콘센트, 표백제, 세제 등) 검사 테스트가 있다.
- [ ] 첫째와 둘째 모두 홈에 "🔬 오늘의 실험" 미션이 있고, 각자 학년에 맞는 카드가 나온다(초3에게 `g5` 카드가 나오지 않음).
- [ ] 초5 흐름에 생각 질문과 변인 바꿔 보기가 나오고, 생각 답이 저장된다.
- [ ] "같이 실험" 모드로 한 번 실험하면 두 아이 도감에 모두 들어가고 각자 예상이 기록된다.
- [ ] 오늘의 카드가 날짜마다 바뀌고, 한 카드는 다시 나오지 않는다(다 하면 처음부터).
- [ ] 배지와 캐릭터 옷차림이 보인다.
- [ ] 보호자 현황에 아이별 실험한 카드, 예상과 결과, 생각 답이 보인다.
- [ ] `npm run typecheck && npm test && npm run build` 통과
