## 병행 진행 제안
T02~T04(영어, AI 필요)와 T05~T07(수학과 재미, AI 불필요)은 서로 다른 파일을 주로 건드리므로 Codex 작업 두 개를 동시에 돌려도 된다.
단, 둘 다 `types.ts`, `store/defaults.ts`, `store/storage.ts`를 고치므로 **나중에 머지하는 쪽이 main을 먼저 받아 충돌을 정리**한다.

## 백로그 (명세서 작성 전)
- 보호자 PIN을 해시로 저장
- 정답과 오답 효과음, 미션 완료 축하 애니메이션
- 주 5일 완료 보너스 쿠폰
- 과학 실험 카드 80장까지 확장, 실험 사진 기록
- 1단계 단어 카드와 따라 말하기 화면을 아이 메뉴에서 완전히 숨기기 (지금은 기본 꺼짐)
- 국어 이야기 2편째 이후, 첫째용(초5) 이야기
- 사회 개념 퀴즈
- 아이 쪽 오답노트 화면
- 유튜브 잠금 운영 가이드 (Family Link 설정법)

## 확인된 사항
- 1단계: 음성 인식(따라 말하기)은 Chrome에서 동작. iPad Safari는 확인 필요.
- Realtime 대화는 WebRTC라 DeX(Chrome)에서 동작해야 함. T02에서 실기기 확인.
