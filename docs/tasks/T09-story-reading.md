# T09 — 국어 연재 이야기 읽기

- 상태: 준비됨 · **다음** (2026-10-08 개정: 하루 미션 → **자유 놀이**, 첫 원고 `docs/stories/small-island.md`)
- 단계: 4
- 선행 작업: 없음 (원고는 기획 쪽에서 작성 완료, **보호자 승인 후 머지**)
- 예상 분량: 하루 (화면 + 원고 데이터 옮기기)

## 목표
책 읽기를 싫어하는 아이도 "다음 화가 궁금해서" 스스로 켜게 만든다. 하루 한 화를 읽고, 끝에 문제 3개를 풀면 다음 날 다음 화가 열린다.

## 배경
원글: 재밌게 쭉쭉 읽다가 마지막에 문제로 뒤통수 맞는 구조, 이야기가 궁금해서 다음 날 알아서 켠다. 그림은 집 PC의 그림 AI로 그렸다.

## 개정 내용 (보호자 결정 2026-10-08)
- 아이들 하루 미션이 이미 35~40분이라 **하루 미션이 아니라 자유 놀이**로 한다. 미션 타입을 추가하지 않고, 별·쿠폰·미션·연속 학습일에 영향이 없다.
- 대신 "오늘 화를 다 풀면 **다음 화는 내일 열려요**"는 그대로 둔다. 다음 화가 궁금해서 스스로 켜게 만드는 게 이 기능의 핵심이다.
- 첫 원고는 기획 쪽에서 썼다: **`docs/stories/small-island.md`** 「작은 섬으로 이사 온 날」(10화, 화마다 약 700~840자, 문제 3개).

## 범위
**포함**
- 홈 화면(아이 프로필) 자유 놀이 카드 "📖 이야기". 보호자가 아이별로 켜고 끌 수 있다(기본: 둘째 켜기, 첫째 켜기 — 첫째도 읽고 싶으면 읽게). 오늘 읽을 화가 있으면 카드에 "새 화 열림!" 표시.
- 이야기 데이터 `src/content/stories/smallIsland.ts`. **원고 문서의 문장을 한 글자도 바꾸지 않고 옮긴다.** 원고 문서의 "구현 규칙"(문단 나누기, 근거 문단 1→0 기준, ✅ 정답 표시)을 따른다.
- 읽기 화면: 큰 글씨(1.25rem 이상, 줄 간격 1.8), 문단 나눔, 선택 그림(`public/stories/<id>/<n>.webp`), 🔊 한국어 읽어 주기(`speak(text, { lang: 'ko-KR' })`, 문단 단위)
- 문제 3개: 사실 확인, 추론, 어휘(뜻 고르기). 4지선다. 틀리면 해당 문단을 강조해 보여 주고 다시 풀기
- 다음 화 잠금: 오늘 화의 문제를 다 맞히면 "내일 열려요 🔒"와 원고의 **다음 화 예고** 한 줄을 보여 준다. 날짜가 바뀌면 열림(하루에 한 화씩만 새로 열림). 이미 연 화는 언제든 다시 읽을 수 있다.
- 마지막 10화를 다 풀면 "이야기 끝! 🎉"과 마지막 예고 문장, 도감처럼 다 읽은 이야기 목록에 표시.
- 이야기 목록, 다 읽은 이야기 다시 보기
- 보호자: 아이 진도, 문제별 정답률, "다음 화 미리 열기" 버튼

**제외**
- AI 이야기 자동 생성 기능 (이야기는 저장소 데이터로 관리)
- 그림 생성 (이미지 파일만 있으면 표시)

## 설계
```ts
interface Story {
  id: string; title: string; level: 'g3' | 'g5';
  episodes: {
    n: number; title: string;
    paragraphs: string[];
    image?: string;
    questions: { type: 'fact' | 'infer' | 'vocab'; q: string; choices: string[]; answer: number; paragraph: number; explain: string }[];
    teaser: string; // 다음 화 예고 한 줄
  }[];
}
// ProfileSettings.stories?: { enabled: boolean }   (선택 필드)
// ProfileData.stories?: Record<storyId, { unlocked: number; finished: number; lastUnlockDate?: string; answers: Record<string, boolean[]> }>
//   (선택 필드, version 2 유지. 화 번호 범위 밖 값은 normalizeState에서 정리, 백업에 포함)
// 순수 함수(src/content/stories/progress.ts):
//   canOpenNext(progress, today): 오늘 화를 다 맞혔고 lastUnlockDate < today 이면 다음 화를 연다
//   recordAnswer(progress, episode, qIndex, correct)
//   storyCardState(progress, today): 'new' | 'reading' | 'locked-until-tomorrow' | 'finished'
```
- 이야기 작성 방법: 기획 쪽(Claude)이 원고를 `docs/stories/`에 쓰고 보호자가 읽고 고친 뒤, 원고 문서의 상태 줄이 "보호자 승인"으로 바뀐 것만 데이터로 옮긴다. **보호자 승인 없는 이야기는 넣지 않는다.**
- 첫 이야기: 둘째가 **동물의 숲**을 좋아하므로 비슷한 분위기의 **창작 이야기**로 한다. 예: 「작은 섬으로 이사 온 날」 — 주인공 아이가 동물 친구들이 사는 섬으로 이사 와서 집을 꾸미고, 사라진 섬의 보물(화석, 희귀 곤충)을 찾아가는 10화. 매 화 끝은 "그런데 그날 밤, 박물관 문이 살짝 열려 있었다…"처럼 궁금하게 끊는다.
  - 게임의 캐릭터 이름, 장소 이름, 설정은 쓰지 않는다(저작권). 동물 친구들 이름은 새로 짓는다.
  - 과학 연결: 곤충, 물고기, 화석, 날씨 같은 소재를 넣어 T08 실험 카드와 이어지게 한다.
- 첫째용 이야기(초5)는 백로그: 로블록스를 좋아하므로 "게임 속 세계를 만드는 아이" 같은 창작 모험물.

## 수용 기준
- [ ] 이야기 1편 10화가 원고와 글자 그대로 일치하고(문단 수·문장 비교 테스트), 화마다 문제 3개(유형별 1개), `answer`와 `paragraph`가 유효하다(테스트).
- [ ] 아이 홈에 "📖 이야기" 자유 놀이 카드가 있고, 보호자가 끄면 사라진다. 미션 목록에는 없다.
- [ ] 오늘 화의 문제를 다 맞히면 다음 화 예고가 나오고, 다음 화는 다음 날 열린다. 하루에 두 화 이상 새로 열리지 않는다(날짜 경계 테스트).
- [ ] 이야기 읽기가 별, 쿠폰, 미션 진행, 연속 학습일에 영향을 주지 않는다(테스트).
- [ ] 틀리면 근거 문단이 강조되고 다시 풀 수 있다.
- [ ] 한국어 읽어 주기가 문단 단위로 동작한다.
- [ ] 보호자 "다음 화 미리 열기"가 동작한다.
- [ ] 375px와 DeX 큰 화면에서 글씨가 크고 편하게 읽힌다. 키보드로 보기 1~4와 Enter 선택이 된다.
