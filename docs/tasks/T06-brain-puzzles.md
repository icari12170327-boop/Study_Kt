# T06 — 두뇌 퍼즐 6종 (하루 10분)

- 상태: 준비됨
- 단계: 3
- 선행 작업: T05 (`NumberPad` 재사용)
- 예상 분량: 이틀 (퍼즐 생성기 1일, 화면과 타이머 1일). 크면 T06a(스도쿠, 숫자 기차, 피라미드) / T06b(저울, 도형 규칙, 블록 세기)로 나눠도 된다.

## 목표
하루 10분 동안 두뇌 퍼즐을 푼다. 문제 수가 아니라 시간을 채우는 방식이라 느리게 생각하는 아이도 손해 보지 않는다. 손을 안 대고 있는 시간은 세지 않고, 3분 막히면 힌트가 나온다. 종류마다 난이도가 따로 자동 조절된다.

## 범위
**포함**
- 미션 타입 `puzzle` (단위: 분, 기본 10, 첫째와 둘째 모두 켬)
- 퍼즐 생성기 6종 (`src/content/puzzles/*.ts`, 모두 시드 고정 순수 함수)
- 퍼즐 세션 화면: 종류는 돌아가며 나오고, 아이가 다음 종류를 고를 수도 있음
- 활동 시간 타이머, 힌트, 종류별 난이도
- 보호자 현황: 종류별 현재 난이도와 최근 정답률

**제외**
- 시간 대결, 순위

## 설계

### 퍼즐 공통 형식
```ts
interface Puzzle {
  type: PuzzleType;
  difficulty: 1 | 2 | 3 | 4 | 5;
  prompt: PuzzleView;      // 화면에 그릴 데이터 (종류별)
  answer: PuzzleAnswer;    // 숫자 하나, 칸 여러 개, 보기 번호
  hint: string;            // 한국어 힌트 한 줄
}
type PuzzleType = 'sudoku' | 'train' | 'pyramid' | 'balance' | 'pattern' | 'blocks';
```

| 종류 | 내용 | 난이도 조절 | 답 입력 |
|---|---|---|---|
| 스도쿠 `sudoku` | 4×4(1~3단계), 6×6(4~5단계) | 빈칸 수. **해가 하나뿐인지 풀이기로 확인**하며 빈칸을 판다 | 칸 선택 + 키패드 |
| 숫자 기차 `train` | 규칙 있는 수열의 다음 수 | 1: +n, 2: -n, 3: ×2, 4: 번갈아 두 규칙, 5: 차이가 커지는 수열 | 키패드 |
| 수 피라미드 `pyramid` | 위 칸 = 아래 두 칸의 합. 빈칸 채우기 | 층 수(3~5), 빈칸 위치(위쪽만 → 아래쪽 섞기) | 칸 선택 + 키패드 |
| 저울 `balance` | 그림 식: 🍎+🍎=10, 🍎+🍌=8 → 🍌=? | 식 개수(1~3), 수 범위 | 키패드 |
| 도형 규칙 `pattern` | 도형, 색, 개수가 바뀌는 줄의 다음 칸 | 속성 수(1~3), 주기 길이 | 보기 4개 |
| 블록 세기 `blocks` | 쌓인 정육면체 개수 (아이소메트릭 SVG) | 바닥 크기 2×2 ~ 3×3, 최대 높이. 숨은 블록은 아래가 받쳐야 하는 규칙으로만 생김 | 키패드 |

### 타이머 규칙
- 10분 = **활동 시간** 기준. 마지막 입력(탭, 키) 후 15초가 지나면 타이머가 멈추고 "계속하려면 화면을 눌러요"가 뜬다.
- 한 퍼즐에서 활동 시간 3분이 지나면 힌트 버튼이 반짝인다(누르면 힌트 표시, 기록).
- 10분이 차면 지금 퍼즐까지만 풀고 끝.
- 진행: 활동 1분마다 `applyProgress({ type: 'puzzle', amount: 1 })`.

### 종류별 난이도 `adjustPuzzleLevel(state, result)` (순수 함수)
- 힌트 없이 연속 3번 맞히면 +1, 틀리거나 힌트를 쓰면 실패 1회, 연속 실패 2회면 -1. 범위 1~5.
- `ProfileData.puzzles: Record<PuzzleType, { level: number; streak: number; fails: number; solved: number }>`
