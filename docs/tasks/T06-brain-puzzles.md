# T06 — 두뇌 퍼즐 6종 (자유 놀이)

- 상태: 준비됨 · **다음** (2026-10-08 개정: 하루 미션 → **자유 놀이**, 두 번으로 나눠 구현)
- 단계: 3
- 선행 작업: T05, T15, T16
- 예상 분량: T06a 하루, T06b 하루

## 개정 내용 (보호자 결정 2026-10-08)
- 처음 명세는 "하루 10분 필수 미션"이었다. 아이들 하루 미션이 이미 35~40분(수학 20문제, 과학 5문제, 영어 대화 15~20분)이라 부담이 커서, **빙고(T16)처럼 홈 화면의 자유 놀이**로 바꾼다.
- 미션 타입을 추가하지 않는다. 별, 쿠폰, 미션 진행, 연속 학습일에 영향이 없다.
- 크기가 커서 두 번으로 나눈다.
  - **T06a**: 공통 틀(화면, 타이머, 힌트, 난이도, 저장) + 스도쿠, 숫자 기차, 수 피라미드
  - **T06b**: 저울, 도형 규칙, 블록 세기 (T06a 틀에 종류만 추가)

## 목표
아이가 하고 싶을 때 두뇌 퍼즐을 푼다. 종류마다 난이도가 따로 자동 조절되고, 막히면 힌트가 나온다. 문제 수가 아니라 생각하는 재미가 중심이다.

## 범위
**포함 (T06a)**
- 홈 화면(아이 프로필) 빙고 카드 옆에 "🧩 두뇌 퍼즐" 카드. 보호자가 아이별로 켜고 끌 수 있다(기본 켜기).
- 퍼즐 고르기 화면: 종류 카드(이름, 그림 예시, 현재 난이도 ★1~5). "🎲 아무거나"는 종류를 돌아가며 낸다.
- 퍼즐 풀이 화면: 한 퍼즐씩, 정답이면 짧은 칭찬 후 같은 종류의 다음 퍼즐, "다른 퍼즐" 버튼으로 종류 바꾸기.
- 활동 시간 표시(선택한 놀이 시간 없음, 그만두고 싶을 때 "그만하기"). 오늘 푼 개수와 활동 시간을 결과에 보여 준다.
- 힌트, 종류별 난이도, 기록 저장, 보호자 현황
- 퍼즐 3종: 스도쿠, 숫자 기차, 수 피라미드

**포함 (T06b)**
- 퍼즐 3종 추가: 저울, 도형 규칙, 블록 세기. 공통 틀은 바꾸지 않고 생성기와 그리기 컴포넌트만 추가.

**제외** (하지 말 것)
- 하루 미션, 별·쿠폰 지급, 시간 대결, 순위
- 외부 퍼즐 라이브러리, 이미지 파일(이모지·CSS·SVG로)

## 설계

### 퍼즐 공통 형식 (`src/content/puzzles/types.ts`)
```ts
export type PuzzleType = 'sudoku' | 'train' | 'pyramid' | 'balance' | 'pattern' | 'blocks';
export type Difficulty = 1 | 2 | 3 | 4 | 5;
export interface Puzzle<V = unknown, A = unknown> {
  type: PuzzleType;
  difficulty: Difficulty;
  seed: number;
  view: V;          // 화면에 그릴 데이터 (종류별)
  answer: A;        // 숫자 하나, 칸 여러 개, 보기 번호
  hint: string;     // 한국어 힌트 한 줄 (초3이 읽을 수 있게)
}
export interface PuzzleGenerator<V, A> {
  type: PuzzleType;
  generate(difficulty: Difficulty, rng: Rng): Puzzle<V, A>;
  check(puzzle: Puzzle<V, A>, input: unknown): boolean;
}
```
- 생성기는 모두 `Rng` 인자를 받는 순수 함수(AGENTS.md 규칙 5). 시드가 같으면 같은 퍼즐.
- 종류 목록 `PUZZLE_TYPES`와 생성기 레지스트리 `GENERATORS: Partial<Record<PuzzleType, PuzzleGenerator>>`. T06a에서는 3종만 등록하고, 등록 안 된 종류는 고르기 화면에 나오지 않는다(T06b가 등록만 추가).

| 종류 | 단계 | 내용 | 난이도 조절 | 답 입력 |
|---|---|---|---|---|
| 스도쿠 `sudoku` | T06a | 4×4(1~3단계), 6×6(4~5단계) | 빈칸 수. **해가 하나뿐인지 풀이기로 확인**하며 빈칸을 판다 | 칸 선택 + 키패드 |
| 숫자 기차 `train` | T06a | 규칙 있는 수열의 다음 수 | 1: +n, 2: −n, 3: ×2, 4: 번갈아 두 규칙, 5: 차이가 커지는 수열 | 키패드 |
| 수 피라미드 `pyramid` | T06a | 위 칸 = 아래 두 칸의 합. 빈칸 채우기 | 층 수(3~5), 빈칸 위치(위쪽만 → 아래쪽 섞기). 답이 하나로 정해지는지 확인 | 칸 선택 + 키패드 |
| 저울 `balance` | T06b | 그림 식: 🍎+🍎=10, 🍎+🍌=8 → 🍌=? | 식 개수(1~3), 수 범위 | 키패드 |
| 도형 규칙 `pattern` | T06b | 도형, 색, 개수가 바뀌는 줄의 다음 칸 | 속성 수(1~3), 주기 길이 | 보기 4개 |
| 블록 세기 `blocks` | T06b | 쌓인 정육면체 개수(아이소메트릭 SVG) | 바닥 2×2~3×3, 최대 높이. 숨은 블록은 아래가 받쳐야 하는 규칙으로만 생김 | 키패드 |

- 학년 차이: 처음 난이도는 둘째 1, 첫째 2. 이후는 종류별 자동 조절.
- 숫자 입력은 `NumberPad`(T15 `window` 리스너) 재사용. 칸 선택은 빙고(T16)의 `moveCell` 방식처럼 방향키로 이동, 숫자로 입력, `Backspace`로 지우기, `Enter`로 확인.

### 활동 시간과 힌트
- 활동 시간은 T05 `activeDuration(events, idleCapMs)` 방식으로 센다. 마지막 입력 후 15초가 지나면 시간이 멈추고 "계속하려면 화면을 눌러요"를 보여 준다. 앱이 백그라운드로 가면 멈춘다(`visibilitychange`).
- 한 퍼즐에서 활동 시간 2분이 지나면 "💡 힌트" 버튼이 반짝인다(자유 놀이라 원래 명세 3분보다 짧게). 누르면 힌트 한 줄 표시, 기록.
- 3번 틀리면 "정답 보기" 버튼도 나온다. 정답을 보면 그 퍼즐은 실패로 기록하고 다음 퍼즐로.

### 종류별 난이도 `adjustPuzzleLevel(state, result)` (순수 함수)
- 힌트 없이 연속 3번 맞히면 +1. 틀리거나(한 퍼즐에서 2번 이상 오답) 힌트·정답 보기를 쓰면 실패 1회, 연속 실패 2회면 −1. 범위 1~5.
- 바뀌면 화면에 "★ 한 단계 올라갔어요" 같은 짧은 안내.

### 저장 (선택 필드, version 2 유지)
```ts
// ProfileSettings
puzzles?: { enabled: boolean };
// ProfileData
puzzles?: {
  levels: Partial<Record<PuzzleType, { level: Difficulty; streak: number; fails: number; solved: number; hinted: number }>>;
  recent: { date: string; type: PuzzleType; difficulty: Difficulty; correct: boolean; hinted: boolean; activeSec: number }[]; // 최근 100개
};
```
- `normalizeState()`: 형식 검사, 범위 밖 레벨은 학년 기본값, `recent` 100개 제한. 백업 내보내기/가져오기 포함.
- 퍼즐 기록은 `mathAttempts`, `wrongNotes`, `mathBySkill`, 수학 레벨에 섞지 않는다.

### 보호자 현황
- 아이별: 종류별 현재 난이도, 최근 7일 푼 개수, 정답률, 힌트 사용 수.
- 아이 설정: "두뇌 퍼즐 켜기/끄기".

## 수용 기준 (T06a)
- [ ] 아이 홈에 "🧩 두뇌 퍼즐" 카드가 있고, 보호자가 끄면 사라진다. 보호자 프로필에는 없다.
- [ ] 스도쿠, 숫자 기차, 수 피라미드를 고르거나 "아무거나"로 풀 수 있다.
- [ ] 각 생성기는 시드가 같으면 같은 퍼즐을 만든다(테스트).
- [ ] 스도쿠는 항상 해가 하나뿐이다(난이도별 생성 200회 테스트). 수 피라미드도 답이 하나로 정해진다(테스트).
- [ ] 입력 없이 15초가 지나거나 앱이 백그라운드로 가면 활동 시간이 멈추고, 다시 누르면 이어진다.
- [ ] 2분 막히면 힌트 버튼이 나오고, 3번 틀리면 정답 보기가 나온다.
- [ ] 종류별 난이도가 규칙대로 오르내리고 저장된다. 둘째는 1, 첫째는 2에서 시작한다.
- [ ] 퍼즐이 별, 쿠폰, 미션 진행, 연속 학습일, 수학 기록에 영향을 주지 않는다(테스트).
- [ ] 마우스, 터치, 키보드(DeX)만으로 각각 퍼즐을 풀 수 있다.
- [ ] 375px 폭과 DeX 큰 화면에서 퍼즐이 잘 보인다(6×6 스도쿠 칸 최소 44px).
- [ ] 보호자 현황에 종류별 난이도와 최근 기록이 보인다.
- [ ] `npm run lint && npm run typecheck && npm test && npm run build` 통과

## 수용 기준 (T06b)
- [ ] 저울, 도형 규칙, 블록 세기가 고르기 화면과 "아무거나"에 추가된다. T06a 3종 동작은 그대로다.
- [ ] 저울의 정답이 그림 식과 일치하고 해가 하나다(테스트).
- [ ] 블록 세기 정답이 높이 맵으로 센 개수와 같고, 숨은 블록은 모두 아래가 받친다(테스트).
- [ ] 도형 규칙의 보기 4개 중 정답이 정확히 하나다(테스트).
- [ ] 각 생성기는 시드가 같으면 같은 퍼즐을 만든다(테스트).
- [ ] `npm run lint && npm run typecheck && npm test && npm run build` 통과

## 리뷰 포인트
- 생성기에 해가 없거나 여러 개인 퍼즐이 나올 가능성, 재시도 상한(무한 반복 방지)
- 초3이 읽을 수 있는 안내 문구와 힌트, 그림만으로도 규칙을 알 수 있는지
- 키 리스너 중복(NumberPad, 칸 이동)과 언마운트 정리
- 자유 놀이가 학습 기록·보상에 섞이지 않는지
