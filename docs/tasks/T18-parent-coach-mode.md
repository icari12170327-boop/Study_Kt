# T18 — 보호자 코치 모드: 한국어로 대답해도 되는 왕초보 영어 회화

- 상태: 준비됨 · **다음**
- 단계: 2 (T04 후속)
- 선행 작업: T04
- 예상 분량: 하루
- 참고: 보호자가 공유한 「AI 원어민 회화 친구 — 뼈대 v0.2」(공익용 공개 문서)의 학습 순서와 대화 규칙을 반영했다.

## 목표
**진짜 초보**인 보호자가 부담 없이 영어로 말문을 연다. 보호자는 한국어로 대답해도 되고, AI 친구가 그 말을 쉬운 영어 문장으로 바꿔 주면 짧게 따라 말한다. 익숙해지면 영어로 대답하고, 끝날 때 오늘 문장 하나를 직접 써 본다. 주제는 **일상 수다**와 **업무·AI 이야기** 중 시작할 때 고른다.

## 배경
- T04 비즈니스 상황극은 상대역이 2~4문장으로 말하고 영어로 대답해야 해서 왕초보에게 어렵다.
- 공유 문서의 핵심(듣기 → 말하기 → 읽기 → 쓰기, 한국어 대답 허용, 짧은 문장, 따라 말하기, 한국어 도움 점점 줄이기)이 지금 보호자 수준에 맞다.
- 비즈니스 상황극(T04)은 그대로 두고, 상황 선택 화면에 **"🌱 코치 모드"**를 추가한다. 코치 모드로 몸을 풀고 익숙해지면 상황극으로 넘어간다.
- 아이들 영어(T03)는 "따라 말하기 없는 자유 수다"로 정했으므로 **바꾸지 않는다.**

## 범위
**포함**
- 상황 선택 화면 맨 위에 "🌱 코치 모드" 카드. 누르면 주제 고르기: "☕ 일상 수다"(하루 일과, 가족, 취미) / "💼 업무·AI 이야기"(내 일, 회의, AI 도구, 테크 뉴스)
- Worker 새 모드 `mode: 'parent-coach'`, `coachTopic: 'daily' | 'work'` (보호자만)
- **대화 규칙** (Worker 지시문, 아래 설계)
  - AI가 먼저 짧게 인사하고 오늘 하루를 하나만 묻는다.
  - 한 번에 짧은 문장 2개까지(한 문장 8단어 안팎), 아주 쉬운 단어(CEFR Pre-A1~A1).
  - 보호자가 한국어로 말하면 알아듣고, 자주(매번은 아니게) 그 말을 쉬운 영어 문장으로 바꿔 **따라 말하기**를 권한다: `Nice! 따라 해 볼까? "I had a busy day."` 그리고 기다린다.
  - 한국어는 짧은 신호("따라 해 볼까?", "이렇게 말해 볼래?")나 보호자가 뜻을 물을 때만.
  - 칭찬은 한 단어. 점수, 문법 설명, 발음 지적은 하지 않는다.
  - 보호자가 영어로 대답하기 시작하면 한국어 도움과 따라 말하기를 조금씩 줄인다.
  - 사람인 척하지 않는다. 회사 이름, 동료 실명, 연락처 같은 정보는 묻지 않고, 나와도 반복하지 않는다.
- **따라 할 문장 카드**: AI 자막에서 큰따옴표 안 영어 문장을 찾아 화면 아래에 크게 띄운다.
  - "🔁 다시 듣기": 브라우저 음성(`speechSynthesis`, `en-US`, 보호자 속도 설정 적용)으로 그 문장을 다시 읽어 준다(비용 0).
  - "⭐ 저장": "내 표현"(T04 `my-phrases`)에 바로 저장. 한국어 뜻은 비워 두고 아래 마무리 단계에서 채운다.
- **소리 먼저, 글자 나중**: 자막 표시 설정 `즉시 / 말 끝난 뒤(기본) / 숨김(눌러서 보기)`. "말 끝난 뒤"는 AI 음성 응답이 끝난 이벤트 후에 그 줄 자막을 보여 준다.
- **"뜻 보기"**: AI 말풍선마다 작은 "뜻" 버튼. 누르면 그 줄만 한국어 뜻을 받아 작게 보여 준다(텍스트 생성 `coach-gloss`, 한 줄씩, 누를 때만 호출).
- **마무리 (대화 끝난 뒤)**
  1. 오늘 같이 쓴 영어 문장 3개를 한국어 뜻과 함께 보여 준다(`coach-wrapup`). 각각 "⭐ 내 표현에 저장".
  2. "하나만 써 볼까요?" 입력 칸. 보호자가 영어로 한 문장 쓰면(한국어 섞여도 됨) 부드럽게 고친 문장과 한국어 한 줄 설명을 보여 준다(`coach-check`). 고친 문장도 저장 가능.
  3. 건너뛰기 가능. 실패해도 대화 기록은 남고 "다시 받기" 버튼.
- **보호자 설정 → 코치 모드** ("내 사용설명서")
  - 수준: `완전 처음(기본) / 단어 몇 개 앎 / 짧은 대화 됨 / 일상 대화 됨`
  - 따라 말하기 양: `적게 / 보통(기본) / 많이`
  - 좋아하는 것(자유 입력, 최대 5개, 기존 `interests` 형식)
  - 말 속도: `0.85(기본) / 0.9 / 1.0`
  - 자막 표시: 위 3가지
  - 친구 이름은 `Alex` 고정(설정 화면 늘리지 않음)
- 미션과 시간: 보호자 `talk` 미션 분에 그대로 합산(T04와 같은 `talkSeconds`), Worker 하루 상한 30분 공유.
- 막힘 대응: 보호자 화면의 "💡 도움" 버튼(T04)을 코치 모드에서는 "🤔 한국어로 도와줘"로 표시, 보내는 신호는 같은 `[STUCK]`.

**제외** (하지 말 것)
- 아이 대화(T03) 변경
- 발음 점수, 녹음 저장
- 영어 외 언어
- 클라우드 TTS 추가(다시 듣기는 브라우저 음성만)

## 설계
### 공통 타입 `shared/ai.ts`
```ts
mode: 'kid-friend' | 'biz-talk' | 'parent-coach';
coachTopic?: 'daily' | 'work';
coach?: { level: 'zero' | 'words' | 'short' | 'daily'; repeat: 'low' | 'mid' | 'high' };
speed?: 0.85 | 0.9 | 1;   // 보호자만. 아이는 서버 고정값(0.85) 유지
export type GenerateKind = … | 'coach-gloss' | 'coach-wrapup' | 'coach-check';
```

### Worker
- `validation.ts`
  - `parent-coach`는 `profileId: 'parent'`, `level: 'adult'`, `coachTopic`과 `coach` 필수, `scenarioId`·`situation` 없음.
  - `speed`는 보호자 세션(`biz-talk`, `parent-coach`)에서만 허용, 값은 0.85/0.9/1만. 아이 세션에 오면 400.
  - 새 생성 종류는 보호자만(`profileId === 'parent'`).
    - `coach-gloss`: 입력 `{ text: string(≤300) }` → 출력 `{ ko: string(≤200) }`
    - `coach-wrapup`: 입력 `{ lines }`(기존 대화 줄 형식) → 출력 `{ sentences: { en: string(≤120); ko: string(≤120) }[] }` 최대 3개
    - `coach-check`: 입력 `{ text: string(≤300), level }` → 출력 `{ corrected: string(≤200); noteKo: string(≤200) }`
- `personas.ts` 코치 지시문 `coachInstructions(req, remaining)`
  - 위 "대화 규칙"을 영어로 쓴다. 공유 문서의 "대화 설정" 10개 규칙을 기본으로 하되, 수준별 차이를 넣는다.
    - `zero`/`words`: 한 문장 6~8단어, 현재형 위주, 따라 말하기를 자주. 세 번째 대답부터 아주 쉬운 영어 대답을 권한다(강요 X).
    - `short`/`daily`: 한 문장 10단어까지, 따라 말하기는 보호자가 막힐 때 위주.
  - `repeat` 양: low = 다섯 번에 한 번쯤, mid = 세 번에 한 번쯤, high = 두 번에 한 번쯤.
  - 주제: `daily`는 하루 일과·가족·취미·음식, `work`는 일·회의·AI 도구·테크 뉴스. 보호자 관심사(`interests`)는 이야깃거리가 떨어질 때만 꺼낸다.
  - 따라 할 문장은 반드시 **큰따옴표 `"…"`** 안에 한 문장만 넣는다(앱이 찾는 규칙).
  - memory, interests는 지금처럼 `escapeData` 후 참고 데이터 블록에.
  - `[STUCK]`를 받으면 한국어 한 문장으로 "한국어로 말해도 돼요" + 쉬운 두 가지 보기를 준다.
  - `[WRAP_UP]`을 받으면 짧게 인사.
- `openai.ts` `buildCallBody`
  - 아이: 지금 그대로(속도 0.85, `eagerness: 'low'`).
  - `parent-coach`: 속도 `req.speed ?? 0.85`, `eagerness: 'low'`(초보는 생각하며 멈춘다), `max_output_tokens` 1000.
  - `biz-talk`: 속도 `req.speed ?? 1`, `eagerness: 'auto'`.
- 테스트: 모드별 세션 설정(속도, eagerness), 검증 거부 케이스(아이에 speed, coach 필드 누락, scenarioId 섞임), 새 생성 종류 입력·출력 스키마, 지시문에 따옴표 규칙·한국어 허용 규칙·개인정보 규칙이 들어 있는지.

### 앱
- 순수 함수 `src/lib/coach.ts`
  - `extractRepeatSentence(text: string): string | null` — 큰따옴표(`"…"`, `“…”`) 안 영어 문장 하나. 한글이 섞였거나 2~120자 밖이면 null.
  - `subtitleVisible(mode, lineState): boolean` — 자막 표시 규칙.
  - `normalizeCoachSettings(raw)` — 기본값과 범위 검사.
- 저장: `ProfileSettings.coach?: { level; repeat; speed; subtitle: 'now' | 'after' | 'hidden' }` (선택 필드, version 2 유지, `normalizeState` 기본값).
- 대화 기록 `TalkLog`에 `mode?: 'coach'`, `coachTopic?` 추가. 기록 화면에서 "🌱 코치" 표시.
- 다시 듣기: `speechSynthesis`가 없으면 버튼을 숨긴다. 영어 음성을 고를 수 없으면 기본 음성.
- "내 표현" 저장은 T04 함수 재사용(중복 방지 그대로). 마무리 단계에서 받은 한국어 뜻으로, 대화 중 뜻 없이 저장한 같은 문장의 `ko`를 채운다.

## 수용 기준
- [ ] 보호자 상황 선택 화면에 "🌱 코치 모드"가 있고, 일상 수다 / 업무·AI 이야기를 고를 수 있다. 아이 화면에는 없다.
- [ ] 코치 모드에서 한국어로 대답해도 AI가 이어 가고, 영어 문장을 큰따옴표로 주며 따라 말하기를 권한다(실제 대화 자막 샘플 PR 첨부, 민감 정보 제거).
- [ ] 따라 할 문장이 화면 아래 카드로 뜨고, "다시 듣기"와 "저장"이 된다.
- [ ] 자막 표시 3가지(즉시 / 말 끝난 뒤 / 숨김)가 동작하고 기본은 "말 끝난 뒤"다.
- [ ] "뜻" 버튼이 그 줄의 한국어 뜻을 보여 준다(누를 때만 요청).
- [ ] 대화가 끝나면 오늘 문장 3개와 뜻, 쓰기 연습과 부드러운 교정이 나온다. 건너뛰기, 실패 후 다시 받기가 된다.
- [ ] 보호자 설정(수준, 따라 말하기 양, 관심사, 말 속도, 자막 표시)이 세션에 반영된다. 말 속도는 비즈니스 상황극에도 적용된다.
- [ ] 코치 모드 대화 시간이 보호자 `talk` 미션에 합산되고 하루 상한(30분)을 함께 쓴다.
- [ ] 아이 대화 설정(속도 0.85 고정, eagerness low, 자막 가림, 막혔어요)은 그대로다(회귀 테스트).
- [ ] `extractRepeatSentence`, `subtitleVisible`, `normalizeCoachSettings` 단위 테스트와 Worker 테스트가 있다.
- [ ] `npm run lint && npm run typecheck && npm test && npm run build` 통과, `cd worker && npm run typecheck && npm test` 통과

## 테스트
- 단위: 따옴표 추출(영어 한 문장, 한글 섞임, 따옴표 없음, 여러 개면 첫 번째, 둥근 따옴표), 자막 규칙, 설정 정규화.
- Worker: 위 설계의 테스트 목록.
- 직접: 보호자 휴대폰에서 일상 수다 5분, 업무·AI 5분. 한국어로만 대답해 보기 → 따라 말하기 → 마무리 쓰기 → "내 표현" 확인.

## 리뷰 포인트
- AI 지시문이 공유 문서의 규칙(짧게, 한 번에 하나, 한국어 신호만, 칭찬 한 단어, 교정 없음)을 지키는지 실제 샘플로 확인.
- 아이 세션에 `speed`나 코치 필드가 들어갈 수 없는지.
- 지시문은 `worker/`에만 있고 앱에는 모드와 데이터만 있는지.
