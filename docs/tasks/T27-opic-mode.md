# T27 — 보호자 오픽(OPIc) 모드: 서베이 맞춤 매일 연습과 실전 모의고사

- 상태: 준비됨 · **다음 (T27a → T27b)** · 2026-10-11 작성
- 단계: 2 (보호자 영어)
- 선행 작업: T22(교정·다시 꺼내기·다시 말하기), T24b(음성 인식 대체)
- 예상 분량: T27a 하루~하루 반 (Worker + 앱) / T27b 하루 (앱 중심)

## 목표
보호자가 오픽 시험을 체계적으로 준비할 수 있다. 내 서베이 주제로 매일 한 문항씩 실제 시험처럼 질문을 듣고 2분 동안 답한다. AI가 오픽 채점 기준에 맞춘 피드백과 **내 경험을 살린 한 단계 위 모범 답안**을 준다. 그 답안을 내 답안 노트에 쌓아 간격을 두고 다시 말한다. 시험 전에는 15문항 실전 모의고사를 본다.

## 배경 (2026-10-11 보호자 결정)
- 목표: **1차 IM2 → 2차 IH**. 시험 날짜는 설정에서 입력한다(없으면 8주 계획).
- 서베이: 아래 기획자 추천 세트를 기본값으로 쓴다. 보호자가 바꿀 수 있다.
- 아이폰에서도 확실히 동작하도록 **서버 받아쓰기**를 쓴다. iOS 홈 화면 앱은 브라우저 음성 인식이 안 될 수 있다(T24b).

### 조사 요약 (2026-10-11, 블로그·앱 소개·ACTFL 자료 교차 확인. 공식 안내로 재확인 필요)
- 시험: 오리엔테이션 약 20분, 본시험 약 40분. 배경 설문(서베이)과 자기 평가(난이도 1~6)를 먼저 한다. 난이도 3~6은 약 15문항이다.
- 15문항 흐름: ① 자기소개 → ②~④, ⑤~⑦, ⑧~⑩ 콤보 세트(보통 **묘사 → 일상·습관 → 과거 경험**) → ⑪~⑬ 롤플레이(**질문하기 → 문제 해결·대안 → 관련 경험**) → ⑭~⑮ 어드밴스(**비교·변화, 사회 이슈**, 난이도 5~6).
- 절반 이상이 서베이 주제에서 나오고, 나머지는 돌발 주제다. 초반 이후 한 번 난이도를 다시 고를 수 있고, 질문은 두 번까지 들을 수 있다고 알려져 있다.
- 등급: NL < NM < NH < IL < IM1 < IM2 < IM3 < IH < AL.
- ACTFL 기준은 할 수 있는 일, 주제·상황, 정확성, 말의 길이와 짜임을 종합해서 본다.
  - IM: 익숙한 주제를 문장이나 문장 여러 개로 말한다.
  - AL: 과거·현재·미래로 문단 길이의 이야기와 묘사를 하고, 문제가 생긴 상황도 해결한다.
  - IH: AL의 일을 자주 해내지만 끝까지 유지하지는 못한다.
- 공통 조언
  - 실제 경험이 많은 주제를 서로 겹치게 고른다.
  - IM2를 노리면 난이도 3~4, IH를 노리면 5를 고른다.
  - 외운 티가 나면 감점이다. 유형별 답변 틀, 연결어, 시간 벌기 표현을 익힌다.
- 기존 AI 도구(오픽미, 오픽이지, 오픽마스터, 오픽업)는 모의고사, 예상 등급, 문장 피드백 중심이다. 초보자용 매일 커리큘럼과 내 답안을 쌓아 다시 말하는 기능은 약하다. 예상 등급의 정확도는 어느 도구도 검증되지 않았다.

## 서베이 기본값 (기획자 추천, 겹치게 고르기)
실제 경험이 많은 가족 활동으로 묶어서 이야기 하나를 여러 질문에 재사용한다. 서베이 항목명은 시험 화면과 다를 수 있으므로 앱에서는 **우리말 주제 이름**으로 쓴다.

| 묶음 | 고를 항목 | 함께 쓰는 이야기 |
|---|---|---|
| 기본 정보 | 직업: **일 경험 없음** 대신 실제대로 **회사원**을 고른다(비즈니스 대화 연습과 겹침) · 학생 아님 · 거주: **가족과 함께 아파트(주택) 거주** | 우리 집, 동네, 출근길, 회사 |
| 바깥 활동 | 여가 **공원 가기**, **해변 가기** · 운동 **걷기**, **조깅** | 아이들과 공원·바닷가 산책 |
| 영상 | 여가 **영화 보기**, **TV·리얼리티 쇼 보기** | 가족 영화의 밤, 좋아하는 프로그램 |
| 음악 | 취미 **음악 감상** | 출퇴근길 음악 |
| 카페 | 여가 **카페 가기** | 주말 카페, 동네 카페 |
| 휴가 | **집에서 보내는 휴가**, **국내 여행** | 가족 여행 |

- 합계 12개 안팎이다. 실제 시험의 최소 선택 수는 보호자가 접수 전에 공식 화면에서 확인한다.
- 돌발 주제는 따로 연습한다: 가구·가전, 날씨·계절, 은행, 병원, 재활용, 교통, 인터넷·기술, 명절, 쇼핑, 음식·요리, 건강, 약속.
- 난이도: 1차(IM2 목표) **3~4**, 2차(IH 목표) **5**.

## T27a — 설정, 질문 은행, 하루 연습, 서버 받아쓰기, AI 피드백, 내 답안 노트

### 화면 흐름
보호자 홈 → **🎯 오픽** (보호자 프로필에만 보임)

1. **처음 설정**: 목표 등급(IM2/IM3/IH/AL, 기본 IM2), 시험 날짜(선택), 난이도(1~6, 기본 4), 서베이 주제(위 기본값 체크, 수정 가능).
2. **오늘의 한 문항** (약 15~20분)
   - ① 오늘의 질문 카드: 유형(자기소개/묘사/일상/과거 경험/비교·변화/롤플레이 질문하기/롤플레이 문제 해결/이슈)과 주제를 보여 준다.
   - ② **답변 틀 보기**(선택, 접기 가능): 유형별 4단계 틀과 연결어 5개, 시간 벌기 표현 3개. 예: 묘사 = 주제 문장 → 세부 3개(어디·무엇·어떤) → 느낌·이유 → 마무리.
   - ③ **실전 답변**: 질문을 TTS로 듣는다(다시 듣기 1회). 20초 준비 표시 뒤 녹음한다. 녹음은 최대 2분이고 언제든 "끝내기"로 마친다. 녹음 중에는 남은 시간 막대를 보여 준다.
   - ④ 받아쓰기 → **AI 피드백**(아래 `opic-feedback`).
   - ⑤ **한 단계 위 모범 답안**: 내가 말한 사실을 살려 다시 쓴 답안이다. 고친 부분은 굵게 표시하고 🔊 듣기를 붙인다.
   - ⑥ **다시 말하기**(선택, 2분): 모범 답안을 보며 한 번 더 녹음한다. 받아쓰기만 하고 피드백은 다시 받지 않는다. 단어 수와 분당 단어 수를 비교해 보여 준다.
   - ⑦ **내 답안 노트에 저장**(기본 체크): 모범 답안을 저장하고 내가 고칠 수 있게 한다.
3. **내 답안 노트**: 유형별·주제별 목록. 답안 보기, 고치기, 🔊 듣기, 삭제.
4. **기록**: 날짜별 문항, 예상 범위, 단어 수, 분당 단어 수, 한국어 비율.

### 오늘의 문항 고르기 (순수 함수, 테스트)
- `pickOpicQuestion(bank, settings, attempts, today)`
  - 서베이 주제 70%, 돌발 주제 20%, 롤플레이·어드밴스 10%로 고른다. 어드밴스는 난이도 5 이상에서만 나온다.
  - 같은 주제 안에서는 **묘사 → 일상 → 과거 경험** 순서로 진도를 나간다. 다음 날 같은 주제의 다음 유형이 나오기 쉽게 한다.
  - 최근 14일에 푼 질문은 제외한다. 후보가 없으면 가장 오래전에 푼 것을 고른다.
  - 같은 날 다시 열면 같은 문항이 나온다. "다른 문항" 버튼은 하루 2번까지다.
- 유형 진도표(주제 × 유형 칸 채우기)를 오픽 홈에 작게 보여 준다.

### 질문 은행 (`src/content/opic/questions.ts`)
- 주제마다 유형별 질문을 1~3개 둔다. 서베이 주제 12개와 돌발 주제 12개를 다룬다. 롤플레이 세트는 주제당 3단계, 어드밴스는 10개 이상이다. **전체 150문항 이상.**
- 문장은 오픽 스타일로 **새로 쓴다**. 시판 교재·기출 문장을 그대로 옮기지 않는다.
- 각 문항 필드는 `id`(바꾸지 않음), `topic`, `type`, `en`(질문), `ko`(질문 뜻), `minLevel`(난이도 1~6)이다.
- 유형별 답변 틀(`frames.ts`)도 둔다: 한국어 설명, 영어 뼈대, 연결어, 시간 벌기 표현.
- **PR 본문에 전체 목록을 표로 적어 보호자가 검토**한다.

### Worker
**새 경로 `POST /api/transcribe` (보호자 전용)**
- 요청: 본문은 녹음 파일 그대로(`Content-Type: audio/webm | audio/mp4 | audio/ogg | audio/mpeg | audio/wav`). 쿼리로 `profileId=parent&durationSec=1~150`을 받는다. 지금 CORS는 `authorization`, `content-type` 헤더만 허용하므로 새 헤더는 쓰지 않는다.
- 크기 상한 **4MB**는 지금 JSON 경로처럼 스트림으로 읽으며 검사한다. Content-Length가 없어도 우회되지 않아야 한다.
- 보호자가 아니면 403, 형식이나 크기가 맞지 않으면 400이다.
- OpenAI 받아쓰기 API를 부른다. 모델은 환경 변수 `TRANSCRIBE_MODEL`(`wrangler.toml`에 기본값)로 정한다. 언어는 지정하지 않는다(한국어 섞임을 그대로 받아 한국어 비율을 계산하기 위해).
- 응답: `{ text }`(≤6000자).
- **녹음 파일은 저장하지 않는다**(KV·로그 모두 금지).
- 한도
  - 하루 `TRANSCRIBE_LIMIT_DAY`(기본 60회), 하루 받아쓰기 시간 `TRANSCRIBE_MINUTES_DAY`(기본 60분)를 넘으면 `limit`이다.
  - 사용량(`/api/usage`)에 받아쓰기 횟수와 초를 보호자 항목으로 보여 준다.
  - 공용 저장 잠금 밖에서 OpenAI를 부르고, 사용량 기록만 잠금 안에서 한다(T20c·T22a 방식).

**새 생성 종류 `opic-feedback` (보호자 전용, 하루 생성 한도 공유)**
- 입력:
  ```ts
  { type: OpicType; topic: string(≤60); question: string(≤400); transcript: string(1~6000);
    durationSec: number(1~150); targetLevel: 'IM2'|'IM3'|'IH'|'AL' }
  ```
- 출력:
  ```ts
  {
    taskDone: boolean;            // 유형이 요구한 일을 했는가(묘사했나, 과거로 말했나, 질문을 3개 했나 등)
    taskNoteKo: string(≤160);
    textType: 'words'|'sentences'|'strings'|'paragraph';  // 말의 길이와 짜임
    levelBand: 'NH-IL'|'IL-IM1'|'IM1-IM2'|'IM2-IM3'|'IM3-IH'|'IH-AL';  // 참고용
    strengthsKo: string(≤120)[] (1~2개);
    corrections: { said(≤200); better(≤160); focus(≤40); whyKo(≤120); pattern }[] (0~3개);  // T22a와 같은 형식·검증
    nextStepKo: string(≤160);     // 다음에 한 가지만 바꿀 것
    modelAnswer: string(≤1400);   // 한 단계 위 답안, 사용자가 말한 사실만 사용
    upgrades: { from(≤120); to(≤160) }[] (0~4개);  // 모범 답안에서 바꾼 핵심 부분
    keyPhrases: string(≤60)[] (2~5개)
  }
  ```
- 지시문(`worker/src/personas.ts`)
  - ACTFL 기준(할 수 있는 일, 말의 길이와 짜임, 정확성, 유창성)으로 판단한다. `levelBand`는 "참고용"이며 과장하지 않는다.
  - **모범 답안은 사용자가 말한 사실만 쓴다.** 새 사실, 숫자, 사람, 장소를 지어내지 않는다. 내용이 부족하면 "예를 들어 ~"처럼 일반적인 연결 문장만 덧붙인다.
  - 목표 등급보다 한 단계 위 수준으로 쓰되, 초보자가 따라 말할 수 있는 길이(120~180단어)로 쓴다.
  - 한국어로 말한 부분은 영어로 바꿔 넣는다.
  - 외운 티가 나는 과한 표현과 관용구 남발을 피한다.
  - 회사명, 금액, 사람 이름 같은 개인정보는 일반화한다(예: my company, a friend).
- 검증
  - `corrections[].said`가 transcript에 없거나 `focus`가 `better`에 없으면 버린다(T22a 함수 재사용).
  - `upgrades[].to`가 `modelAnswer`에 없으면 버린다.
- 기존 짧은 생성의 1회 재시도 규칙을 따른다. 시간 초과는 이 종류만 20초로 한다(긴 출력).
- 테스트: 스키마, 권한(아이 거부), 검증 필터, 지시문 규칙 문장, transcribe 크기·형식·한도·권한, 녹음을 저장하지 않는지.

### 앱 저장 (선택 필드, version 2 유지)
```ts
// ProfileData(parent)에 추가
opic?: {
  settings: { targetLevel: 'IM2'|'IM3'|'IH'|'AL'; examDate?: string; difficulty: 1|2|3|4|5|6; survey: string[] };
  attempts: OpicAttempt[];   // 최대 200개, 오래된 것부터 정리
  scripts: OpicScript[];     // 최대 150개
  skipsByDate?: Record<string, number>;  // "다른 문항" 횟수, 최근 7일만 보관
};
interface OpicAttempt {
  id: string; date: string; questionId: string; type: OpicType; topic: string;
  transcript: string(≤6000); durationSec: number; words: number; wpm: number; koreanRatio: number;
  feedback?: OpicFeedback; retell?: { transcript: string; durationSec: number; words: number; wpm: number };
}
interface OpicScript { id: string; questionId: string; type: OpicType; topic: string; text: string(≤1600); createdAt: string; updatedAt: string }
```
- `normalizeState`: 형식, 길이, 날짜, 개수, 알 수 없는 type이나 topic을 정리한다. 아이 데이터에는 만들지 않는다. 백업 왕복 테스트를 붙인다.
- 녹음 파일은 앱에도 저장하지 않는다. 받아쓰기 텍스트만 남긴다.

### 녹음 (`src/lib/recorder.ts`)
- `MediaRecorder`로 녹음한다. 지원 형식은 `audio/webm;codecs=opus`, 그다음 `audio/mp4`(iOS Safari) 순서로 고른다.
- 최대 2분이 되면 자동으로 멈춘다. 화면을 나가거나 숨기면 녹음을 멈추고 마이크 트랙을 정리한다.
- 권한이 거부되거나 지원하지 않으면 "글로 답하기"로 바꾼다. 입력칸에 쓴 답으로 같은 피드백을 받는다. 시간 측정은 입력 시작부터 끝까지다.
- 업로드에 실패하면 녹음을 메모리에 두고 "다시 보내기"를 보여 준다(화면을 나가면 버린다).

### 수용 기준 (T27a)
- [ ] 보호자 홈에 🎯 오픽이 있다. 처음 설정에서 목표, 날짜, 난이도, 서베이(기본값 체크)를 정할 수 있다. 아이 프로필에는 없다.

## T27b — 주간 계획, 내 답안 다시 말하기, 실전 모의고사

### 주간 계획
- 시험 날짜에서 거꾸로 계산한다(날짜가 없으면 8주). 주차별 초점은 다음과 같다.

  | 주차 비율 | 초점 |
  |---|---|
  | 처음 25% | 자기소개 + 서베이 주제 묘사·일상 |
  | 다음 25% | 서베이 주제 과거 경험 + 돌발 주제 묘사 |
  | 다음 25% | 롤플레이 3단계 + 비교·변화 |
  | 마지막 25% | 약한 유형 집중 + 실전 모의고사 주 2회 |

- 오늘의 문항 고르기에 이번 주 초점 가중치를 준다.
- 오픽 홈 상단에 "시험까지 D-n · 이번 주 초점 · 이번 주 연습 n/5회"를 보여 준다.

### 내 답안 다시 말하기 (간격 반복)
- 노트에 저장한 답안에 `stage`(0~3)와 `dueDate`(1→3→7일)를 둔다. T22a의 갱신 함수를 재사용한다.
- 하루 연습 시작 전에 기한이 된 답안 1개를 "어제 답안 다시 말하기(1분 30초)"로 보여 준다.
  - 답안을 가린 채 키워드 3개만 보여 주고 녹음한다.
  - 받아쓰기 후 핵심 표현(`keyPhrases`) 사용 수로 성공과 실패를 판정한다(AI 호출 없음).

### 실전 모의고사
- **자기 평가 화면 → 15문항**으로 진행한다.
  - 구성: 자기소개, 콤보 3세트(서베이 2 + 돌발 1), 롤플레이 1세트, 어드밴스 2(난이도 5 이상, 4 이하면 콤보 1세트로 대체).
- 문항마다 질문 듣기(다시 듣기 1회, 5초 안에) → 녹음(최대 2분 30초)을 한다.
- 7번 문항이 끝나면 "쉽게 / 그대로 / 어렵게"를 고른다. 이후 문항의 `minLevel`을 조정한다.
- 전체 시간 40분 타이머를 둔다. 넘어도 끊지는 않고 표시만 한다.
- 받아쓰기는 문항마다 바로 하고, 피드백은 끝난 뒤 한꺼번에 받는다(동시 요청 최대 3개).
- 결과 화면
  - 문항별 유형, 단어 수, 과제 달성, 예상 범위를 보여 준다.
  - **약한 유형 Top 3**와 다음 주 초점 추천을 보여 준다.
  - 전체 예상 범위는 문항별 범위의 중앙값으로 정하고 "참고용"이라고 표시한다.
- 중간에 나가면 진행 상태를 저장하고 이어 보기를 할 수 있다(그날만).
- 비용 안내: 모의고사 1회 = 받아쓰기 약 15회 + 피드백 15회. 시작 전에 남은 하루 한도를 보여 주고, 부족하면 시작하지 않는다.

### 기타
- 보호자 주간 리포트(T13)의 "보호자 영어" 칸에 오픽 연습 횟수, 평균 단어 수, 최근 예상 범위를 추가한다.
- 보호자 미션에 "오픽 1문항"(선택, 기본 꺼짐)을 추가한다. 끝내면 대화 미션과 별도로 진행한다.

### 수용 기준 (T27b)
- [ ] 주간 계획이 시험 날짜에서 계산되고, 이번 주 초점이 오늘의 문항에 반영된다(테스트).
- [ ] 내 답안 다시 말하기가 1→3→7일로 돌고, 키워드 판정으로 성공과 실패가 갱신된다(테스트).
- [ ] 실전 모의고사 15문항이 실제 흐름(다시 듣기 1회, 7번 뒤 난이도 조정, 40분 표시)으로 진행되고, 중간에 나가도 이어 볼 수 있다.
- [ ] 결과 화면에 문항별 결과, 약한 유형 Top 3, 참고용 예상 범위가 있다. 하루 한도가 부족하면 시작하지 않는다.
- [ ] 주간 리포트와 보호자 미션(선택)이 연결된다. 아이 리포트는 바뀌지 않는다.
- [ ] `normalizeState`·백업 테스트가 있고 version 2를 유지한다. 앱·worker 검사를 통과한다.

## 리뷰 포인트
- 모범 답안이 사용자가 말하지 않은 사실을 지어내지 않는지, 개인정보가 일반화되는지
- 예상 범위를 과장하지 않는지("참고용" 표시)
- 녹음 파일이 서버와 앱 어디에도 남지 않는지, 마이크 트랙이 항상 정리되는지
- 받아쓰기 한도와 비용: 하루 연습 1회 = 받아쓰기 1~2회 + 피드백 1회, 모의고사 1회 = 받아쓰기 약 15회 + 피드백 15회
- 질문 은행이 기출을 베끼지 않았는지
- 실제 체감(문항 난이도, 피드백 길이, 모범 답안 길이)은 **배포 후 보호자가** 일주일 써 보고 조정
