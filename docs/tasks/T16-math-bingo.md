# T16 — 수학 빙고판: 합이 맞는 숫자 3개 찾아 줄 긋기

- 상태: 완료 (PR #25)
- 단계: 3 (놀이형 수학)
- 선행 작업: T05 (레벨), T15 (키보드 처리 재사용)
- 예상 분량: 하루

## 목표
아이가 숫자판에서 **"합이 □이 되는 숫자 3개"를 찾아 한 줄로 긋는** 게임을 할 수 있다. 첫째가 직접 요청한 게임이고, 둘째도 쉬운 판으로 같이 한다.

## 배경
- 첫째(초5) 요청: "숫자판에서 문제에서 말한 수가 되도록 숫자 3개를 찾아 한 줄로 긋는 빙고판".
- 수학 도전(T05)은 문제 풀이형이고, 이 게임은 **여러 수를 훑으며 더해 보는 암산 놀이**라 성격이 다르다. 수 감각과 빠른 덧셈 연습에 좋다.
- 미션이 아니라 **자유 놀이**로 둔다. 하고 싶을 때 하는 게임이어야 아이가 계속 좋아한다.

## 규칙 (보호자 확인 완료)
보호자가 아이와 확인했다 (2026-10-07). 이 절의 규칙을 그대로 구현한다.
1. ✅ 숫자판은 **앱이 채운다** (아이가 직접 숫자를 써 넣는 방식은 2차 후보, 아래 "후속 후보").
2. ✅ 세 숫자는 **가로, 세로, 대각선으로 붙어 있는 3칸**이다 (떨어진 칸 X).
3. ✅ 둘째는 **덧셈만**. 첫째는 **곱셈을 넉넉히** 섞는다 (보호자 확인: 곱셈 더 많이). 한 판 5개 중 기본 2~3개가 "곱이 □" 문제.
4. ✅ 한 판에 문제 5개, 5개를 다 찾으면 "빙고!" 하고 새 판으로 넘어간다.
5. ✅ **시간 제한 있음** (첫째 요청): 제한 시간 안에 최대한 많이 찾는 타임어택이 기본. 정답마다 +5초 보너스.

## 범위
**포함**
- 홈 화면에 "🎯 수학 빙고" 카드 (미션 목록 아래, 아이 프로필만). 하루 미션 완료 여부와 무관.
- 판 크기와 숫자 범위 (레벨별)
  | 레벨 | 판 | 칸 숫자 | 목표 수 | 곱 문제 |
  |---|---|---|---|---|
  | g3 (둘째) | 5×5 | 1~9 | 6~24 | 없음 |
  | g5 (첫째) | 6×6 | 1~20 (곱 문제가 나오는 판은 1~12 칸을 절반 이상) | 합 10~50, 곱 12~400 | 5문제 중 2~3개 (보호자 설정: 적게 1 / 보통 2~3 / 많이 4) |
- 시작 화면에서 두 가지 중 고른다.
  - **⏱️ 타임어택 (기본)**: 제한 시간 동안 최대한 많은 목표를 찾는다. 제한 시간 기본값은 둘째 3분, 첫째 2분 (보호자가 1~5분, 30초 단위로 조절).
  - **🐢 연습**: 시간 제한 없이 한 판(목표 5개). 기록은 남기지 않는다.
- 게임 흐름: 목표 "합이 15가 되는 3칸을 찾아 줄을 그어요" → 아이가 줄을 그음 → 채점 → 다음 목표. 한 판의 목표 5개를 모두 찾으면 "빙고!" 표시 후 새 판으로 바뀌고 계속한다(타임어택).
- 타이머 규칙 (타임어택)
  - 화면 위에 남은 시간 막대와 초. 10초 남으면 막대 색이 바뀌고 숫자가 커진다.
  - 정답마다 **+5초** (화면에 "+5초" 잠깐 표시). 남은 시간은 처음 제한 시간을 넘지 않는다.
  - "⏭️ 패스" 버튼: 지금 목표를 건너뛰고 다음 목표로 (판의 목표 수에는 포함, 점수는 0). 남용 방지로 패스 후 3초 동안 다시 누를 수 없다.
  - 시작 전 "3, 2, 1" 카운트다운. 0초가 되면 입력을 막고 "시간 끝!" → 결과 화면.
  - 앱이 백그라운드로 가거나 화면이 꺼지면(`visibilitychange`) 타이머를 멈추고 "계속하기" 버튼을 보여 준다. 시간 계산은 `Date.now()` 차이로 해서 탭이 느려져도 어긋나지 않게 한다.
- 줄 긋기 입력 (세 가지 모두 지원)
  - **드래그**: 첫 칸에서 눌러 셋째 칸에서 뗀다 (터치, 마우스, Pointer Events).
  - **탭 3번**: 칸을 차례로 누르면 선택 표시, 3칸이 되면 자동 채점. 같은 칸을 다시 누르면 선택 취소.
  - **키보드 (DeX)**: 방향키로 칸 이동, Enter/Space로 선택, Backspace로 마지막 선택 취소, Esc로 전체 취소. T15처럼 `window` 단위로 받고, 입력 칸이나 PIN 모달에 포커스가 있으면 가로채지 않는다.
- 채점과 피드백
  - 정답: 세 칸 위에 굵은 선(SVG)을 남기고 "딩!" 표시. 이미 쓴 칸도 다음 문제에서 다시 쓸 수 있다(판이 금방 막히지 않게).
  - 오답: 칸을 살짝 흔들고 실제 계산을 보여 준다. 예: "4 + 5 + 3 = 12, 목표는 15야". 선은 지운다.
  - 줄이 아닌 칸(붙어 있지 않거나 꺾인 3칸): "한 줄로 붙어 있는 3칸을 골라요".
  - 힌트: 한 목표에서 20초(연습은 40초)가 지나면 "💡 힌트" 버튼이 나타나고, 누르면 정답 줄의 가운데 칸 하나를 반짝인다. 타임어택에서는 힌트를 쓰면 **3초 차감**.
- 결과 화면 (타임어택): 찾은 개수, 빙고(완성한 판) 수, 힌트 수, 내 최고 기록(같은 제한 시간 기준 찾은 개수 최대), 새 기록이면 "🎉 새 기록!", "한 판 더" 버튼.
- 기록 저장: 프로필별 최근 기록과 최고 기록.

**제외** (하지 말 것)
- 시간 제한 압박이 심하면 둘째용 기본을 연습 모드로 바꾸는 것은 보호자 피드백 후 결정 (지금은 둘 다 타임어택 기본).
- 별, 쿠폰 지급 (`applyProgress` 연결 없음). 보상과 형제 대결 연결은 T07에서 검토.
- 아이가 숫자판을 직접 채우는 모드, 두 사람 대전, 뺄셈/나눗셈 문제.
- 효과음 파일 추가 (기존 피드백 방식 재사용).

## 설계
### 데이터 모델
`src/types.ts`
```ts
export interface BingoRecord {
  date: string;
  level: Level;
  /** 제한 시간(초). 기록은 같은 제한 시간끼리만 비교한다. */
  limitSec: number;
  found: number;
  bingos: number;
  hints: number;
}
// ProfileData에 추가 (선택 필드라 버전 올리지 않음). 연습 모드는 기록하지 않는다.
bingo?: { recent: BingoRecord[]; best: Record<string, BingoRecord> }; // best 키: String(limitSec)
```
- `normalizeState()`: `bingo`가 없거나 형식이 틀리면 `{ recent: [] }`. `recent`는 최신 20개만 유지. 숫자 필드가 유한한 0 이상 정수가 아니면 그 기록은 버린다. `best`가 객체가 아니면 `{}`.
- 백업 가져오기에서도 같은 정규화가 적용되는지 테스트.

### 순수 로직 `src/content/math/bingo.ts`
```ts
export type Cell = { r: number; c: number };
export type BingoOp = 'sum' | 'product';
export interface BingoGoal { op: BingoOp; target: number }
export interface BingoBoard { size: number; grid: number[][]; goals: BingoGoal[] }

/** 판 하나와 목표 5개를 만든다. 모든 목표에 정답 줄이 최소 1개 있다. */
export function generateBingoBoard(level: 'g3' | 'g5', rng: Rng, opts?: { productMix?: 'off' | 'few' | 'normal' | 'many' }): BingoBoard;
/** 3칸이 가로/세로/대각선으로 붙은 한 줄인지. 순서는 양방향 모두 허용(가운데 칸은 반드시 가운데). */
export function isStraightLine(cells: Cell[]): boolean;
/** 선택한 3칸을 채점한다. */
export function checkLine(board: BingoBoard, goal: BingoGoal, cells: Cell[]):
  | { ok: true }
  | { ok: false; reason: 'not-line' }
  | { ok: false; reason: 'wrong'; values: number[]; result: number };
/** 목표를 만족하는 모든 줄 (힌트, 생성 검증용). 같은 줄의 역순은 하나로 센다. */
export function findLines(board: BingoBoard, goal: BingoGoal): Cell[][];
/** 드래그 시작 칸과 끝 칸으로 3칸 줄을 만든다. 거리가 정확히 2칸인 직선이 아니면 null. */
export function lineFromEnds(a: Cell, b: Cell): Cell[] | null;

/** 타이머 순수 로직. 화면은 now만 넘긴다. */
export interface BingoClock { limitMs: number; remainingMs: number; runningSince?: number }
export function startClock(limitSec: number, now: number): BingoClock;
export function remaining(clock: BingoClock, now: number): number;      // 0 미만이면 0
export function pauseClock(clock: BingoClock, now: number): BingoClock;
export function resumeClock(clock: BingoClock, now: number): BingoClock;
/** 정답 보너스(+5초)와 힌트 차감(-3초). 결과는 0~limitMs로 자른다. */
export function adjustClock(clock: BingoClock, now: number, deltaMs: number): BingoClock;
/** 새 기록이면 best를 바꾼 새 객체를 돌려준다. 같으면 힌트 적은 쪽이 이긴다. */
export function updateBest(best: Record<string, BingoRecord>, rec: BingoRecord): { best: Record<string, BingoRecord>; isNew: boolean };
```
- 생성 방법: 숫자판을 무작위로 채운 뒤, 무작위 줄 하나를 골라 그 합(또는 곱)을 목표로 삼는다. 목표 범위를 벗어나면 다시 고른다. **같은 목표가 한 판에 두 번 나오지 않게** 한다.
- 정답 줄이 너무 많으면(예: 4개 초과) 그 목표는 버리고 다시 고른다. 너무 쉬워지는 것을 막는다.
- 곱 문제는 g5에서만. 한 판의 곱 목표 수: `off` 0, `few` 1, `normal` 2~3(난수), `many` 4. 합과 곱 순서는 섞는다.
- 곱 줄은 1이 하나라도 있으면 버리고(너무 쉬움), 곱이 12~400 밖이면 버린다. 큰 수끼리만 모이지 않도록 곱 문제가 있는 판은 칸의 절반 이상을 1~12로 채운다(구구단 범위 위주).
- 한 판 안에서 같은 숫자 세 개 묶음이 합 목표와 곱 목표의 정답으로 동시에 쓰이지 않게 한다(헷갈림 방지).
- 난수는 `Rng` 인자로만 (AGENTS.md 규칙 5).

### 화면 `src/pages/MathBingo.tsx`
- 라우트 추가: `src/route.ts`의 `Route`에 `{ name: 'bingo', profileId }` 형태로 기존 방식대로.
- 칸은 정사각형 버튼, 최소 56px(5×5), 48px(6×6). Fold4 펼친 화면과 DeX 큰 화면에서 판이 화면 높이를 넘지 않게 `min(90vw, 70vh)` 기준으로 맞춘다.
- 선은 판 위에 겹친 `<svg>`로 그린다. 다크 모드에서 보이도록 `--primary` 계열 CSS 변수를 쓴다.
- 문구 예: "합이 **15**가 되는 3칸을 찾아 한 줄로 그어요", "곱이 **60**이 되는 3칸…", 결과 "빙고! 5개 모두 찾았어요".
- 접근성: 각 칸 `aria-label="3행 2열, 7"`, 선택 상태 `aria-pressed`.

### 보호자 설정
- 보호자 모드 → 아이 설정에 "수학 빙고: 켜기/끄기"(기본 켜기), "제한 시간"(1~5분, 30초 단위, 기본 둘째 180초·첫째 120초), 첫째에게만 "곱셈 문제 양"(끄기/적게/보통/많이, 기본 보통). `ProfileSettings`에 선택 필드 `bingo?: { enabled: boolean; productMix: 'off' | 'few' | 'normal' | 'many'; limitSec: number }`로 두고 `normalizeState()`에서 기본값을 채우고 범위를 벗어나면 기본값으로 되돌린다.

## 수용 기준
- [ ] 아이 프로필 홈에 "🎯 수학 빙고" 카드가 있고, 보호자가 끄면 사라진다. 보호자 프로필에는 없다.
- [ ] 둘째는 5×5(1~9), 첫째는 6×6(1~20) 판이 나오고 한 판에 목표가 5개다.
- [ ] 첫째 판은 기본(보통)에서 5개 중 2~3개가 곱 문제이고, 보호자 설정(끄기/적게/많이)에 따라 0/1/4개로 바뀐다. 둘째 판에는 곱 문제가 없다.
- [ ] 타임어택에서 "3, 2, 1" 뒤 타이머가 줄고, 정답마다 +5초(제한 시간 초과 불가), 힌트마다 -3초가 반영된다.
- [ ] 0초가 되면 입력이 막히고 결과 화면에 찾은 개수, 빙고 수, 힌트 수, 같은 제한 시간 최고 기록이 나온다.
- [ ] 한 판 5개를 다 찾으면 "빙고!" 뒤 새 판으로 바뀌고 타이머는 이어진다.
- [ ] 앱을 백그라운드로 보냈다 돌아오면 타이머가 멈춰 있고 "계속하기"로 이어 갈 수 있다.
- [ ] 연습 모드는 타이머가 없고 기록을 남기지 않는다.
- [ ] 보호자가 제한 시간을 바꾸면 다음 게임부터 적용되고, 최고 기록은 제한 시간별로 따로 보인다.
- [ ] 생성된 모든 목표에 정답 줄이 1~4개 있다 (시드 여러 개로 단위 테스트).
- [ ] 드래그, 탭 3번, 키보드(방향키+Enter) 세 방식 모두로 줄을 그어 채점할 수 있다.
- [ ] 정답이면 선이 남고 다음 목표로 넘어가며, 오답이면 실제 계산식이 보이고 다시 시도할 수 있다.
- [ ] 붙어 있지 않거나 꺾인 3칸은 "한 줄" 안내가 나오고 오답 횟수로 치지 않는다.
- [ ] 한 목표에서 20초(연습 40초) 뒤 힌트 버튼이 나오고, 누르면 정답 줄 가운데 칸이 강조된다.
- [ ] 패스하면 다음 목표로 넘어가고 3초 동안 패스 버튼이 비활성화된다.
- [ ] 타임어택 기록이 저장되고 새로고침 후에도 최고 기록이 남아 있다.
- [ ] `bingo` 필드가 없는 기존 데이터, 잘못된 형식의 백업도 오류 없이 열린다.
- [ ] 별, 쿠폰, 연속 학습일이 바뀌지 않는다.
- [ ] `isStraightLine`, `lineFromEnds`, `checkLine`, `findLines`, `generateBingoBoard`, 타이머 함수들, `updateBest` 단위 테스트가 있다.
- [ ] `npm run lint && npm run typecheck && npm test && npm run build` 통과

## 테스트
- 단위: 줄 판정(가로/세로/두 대각선, 역순, 꺾인 줄, 떨어진 칸, 판 밖 좌표), 합/곱 채점, 생성기 시드 100개에서 목표 범위·중복 없음·정답 줄 1~4개·곱 목표 개수(off/few/normal/many)·곱 줄에 1 없음.
- 단위: 타이머(멈춤/재개 중 시간 안 줄어듦, 보너스가 제한 시간을 넘지 않음, 차감이 0 아래로 안 감), `updateBest`(더 많이 찾으면 갱신, 같으면 힌트 적은 쪽, 다른 제한 시간은 따로).
- 직접: Fold4 DeX에서 마우스 드래그, 터치 드래그, 키보드만으로 한 판씩. 폰(375px)에서 판이 잘리지 않는지.

- 생성기가 무한 반복에 빠질 수 없는지 (재시도 상한과 실패 시 처리).

- 키보드 처리가 T15의 수학 도전 리스너와 겹치지 않는지 (화면 언마운트 시 제거).
