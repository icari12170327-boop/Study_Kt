# T15 — DeX 물리 키보드로 수학 도전 끝까지 풀기

- 상태: 준비됨
- 단계: 3 (T05 후속, 우선순위 높음)
- 선행 작업: T05
- 예상 분량: 반나절 이하

## 목표
아이들이 Fold4 + DeX에서 **물리 키보드만으로** 수학 도전 20문제를 끝까지 풀 수 있다. 화면을 마우스로 어디를 클릭하든 숫자, Backspace, Enter가 계속 먹는다.

## 배경
T05 리뷰(🟣): 키 입력 처리가 `NumberPad` 컨테이너의 `onKeyDown`에만 있어서, 입력 칸이나 키패드 밖을 클릭해 포커스가 빠지면 키보드 입력이 먹지 않는다. 답을 제출하면 입력 칸이 `disabled`가 되면서 포커스가 사라질 수도 있다. 아이들의 주 사용 환경이 DeX(키보드, 마우스)라서 실제 사용에서 바로 걸리는 문제다.

## 범위
**포함**
- 수학 도전 화면이 떠 있는 동안 **문서 단위(`window`) 키 이벤트**로 숫자 입력을 받는다. `NumberPad` 컨테이너의 `onKeyDown`은 제거하거나 중복 처리되지 않게 정리한다.
  - `0`~`9`, `.`(소수 문제만), `Backspace`, `Delete`: 현재 칸에 입력
  - `Enter`: 채점 전이면 확인, 오답 피드백 상태면 "다음 문제"
  - `Tab` / `Shift+Tab` 또는 `→` / `←`: 분수(자연수, 분자, 분모)와 몫/나머지 칸 사이 이동
  - 키패드(텐키) 숫자도 같은 동작 (`event.key` 기준이면 자동으로 됨)
- 다른 입력 요소(보호자 PIN 모달, 텍스트 입력 칸)에 포커스가 있을 때는 가로채지 않는다.
- 화면을 떠나면(언마운트) 리스너를 반드시 제거한다.
- 키 처리 로직은 순수 함수로 분리: `mapKeyToAction(key, { kind, phase }) → PadAction | null`

**제외**
- 다른 화면(단어, 퍼즐 등)의 키보드 지원 (T06은 이 함수를 재사용하도록 명세에 추가 예정)
- 단축키 안내 화면

## 수용 기준
- [ ] 수학 도전에서 화면 빈 곳, 상단 바, 키패드 버튼을 클릭한 뒤에도 키보드 숫자, Backspace, Enter가 동작한다.
- [ ] 답 제출 후(정답 자동 넘김, 오답 피드백) Enter만으로 다음 문제로 갈 수 있고, 다음 문제에서 바로 키보드 입력이 된다.
- [ ] 분수와 몫/나머지 문제에서 Tab 또는 화살표로 칸을 옮길 수 있다.
- [ ] 키를 꾹 눌러도(키 반복) 확인이 여러 번 제출되지 않는다.
- [ ] PIN 모달이 열려 있으면 수학 화면이 키 입력을 가로채지 않는다.
- [ ] 화면 숫자 키패드(터치, 마우스) 동작은 그대로다.
- [ ] `mapKeyToAction` 단위 테스트가 있다.
- [ ] `npm run lint && npm run typecheck && npm test && npm run build` 통과

## 테스트
- 직접: DeX(또는 PC Chrome)에서 마우스로 여기저기 클릭하며 키보드만으로 20문제 풀기
